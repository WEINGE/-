# 智能基准压力标定系统 - 快速参考卡片

## ? 快速开始（5分钟集成）

### 1. 添加头文件
```c
#include "smart_baseline_calibration.h"
```

### 2. 初始化（在系统启动时）
```c
float initial_baseline = wf5803f_get_baseline_pressure();
smart_calibration_init(initial_baseline);
```

### 3. 添加采样（每次读传感器后）
```c
smart_calibration_add_sample(pressure_hpa, temperature_c, timestamp_ms);
```

### 4. 定时检查（每小时）
```c
smart_calibration_schedule(current_time_ms, rtc_hour);
```

## ?? 关键参数一览表

| 参数 | 默认值 | 说明 | 调整指南 |
|------|--------|------|----------|
| `CALIBRATION_MIN_INTERVAL_MS` | 86400000 | 最小标定间隔(24h) | 稳定环境可减少到12h |
| `CALIBRATION_MAX_INTERVAL_MS` | 604800000 | 最大标定间隔(7天) | 波动环境可缩短到3天 |
| `CALIBRATION_CHECK_INTERVAL_MS` | 3600000 | 检查间隔(1h) | 通常不需要调整 |
| `FLOOD_DETECTION_DELTA_HPA` | 8.0 | 水浸检测阈值(8hPa=8cm) | 提高灵敏度改为5.0 |
| `FLOOD_CONTINUOUS_COUNT` | 3 | 连续确认次数 | 降低误报改为5 |
| `STABILITY_PRESSURE_VARIANCE_HPA` | 0.5 | 压力稳定性阈值 | 波动环境改为1.0 |
| `STABILITY_TEMP_VARIANCE_C` | 0.3 | 温度稳定性阈值 | 波动环境改为0.5 |
| `CALIBRATION_WINDOW_START_HOUR` | 2 | 时间窗口开始(2点) | 根据实际调整 |
| `CALIBRATION_WINDOW_END_HOUR` | 5 | 时间窗口结束(5点) | 根据实际调整 |

## ? 常见问题速查

### 问: 标定从不执行？
```
检查列表:
? 时间窗口设置（默认凌晨2-5点）
? RTC时间是否正确
? 距离上次标定是否>=24小时
? 环境是否稳定（查看日志variance值）
? 采样数据是否足够（至少8个）

快速解决：
smart_calibration_set_time_window_enable(false);  // 禁用时间窗口
smart_calibration_force_trigger(false);           // 手动触发
```

### 问: 频繁误报水浸？
```
调整参数:
#define FLOOD_DETECTION_DELTA_HPA  12.0f  // 提高阈值
#define FLOOD_CONTINUOUS_COUNT     5      // 增加确认次数

或者：
smart_calibration_set_flood_prevention_enable(false);  // 临时禁用
```

### 问: 标定后精度反而下降？
```
可能原因：在不稳定环境标定
解决方法：
1. 查看标定时的日志，检查variance值
2. 如果方差过大，说明环境不稳定
3. 调整稳定性阈值更严格：
   #define STABILITY_PRESSURE_VARIANCE_HPA  0.3f
```

### 问: 如何立即强制标定？
```c
// 带安全检查的强制标定（推荐）
smart_calibration_force_trigger(false);

// 跳过所有检查（危险！仅调试用）
smart_calibration_force_trigger(true);

// 或通过BLE发送命令
{"cmd":"ForceCalibration","skip_checks":false}
```

## ? 状态码速查

### calibration_state_t
```
0 = IDLE           空闲
1 = CHECKING       正在检查条件
2 = COLLECTING     正在收集数据
3 = VALIDATING     正在验证
4 = EXECUTING      正在执行标定
5 = SUCCESS        标定成功
6 = FAILED         标定失败
```

### calibration_fail_reason_t
```
0 = NONE             无失败
1 = FLOOD_DETECTED   检测到水浸
2 = UNSTABLE_ENV     环境不稳定
3 = TIME_WINDOW      不在时间窗口
4 = TOO_SOON         距离上次太近
5 = ABNORMAL_DELTA   压力变化异常
6 = SENSOR_ERROR     传感器错误
```

## ? 紧急救援

### 系统异常，需要立即标定
```c
// 1. 禁用所有安全检查
smart_calibration_set_time_window_enable(false);
smart_calibration_set_stability_check_enable(false);
smart_calibration_set_flood_prevention_enable(false);

// 2. 强制立即标定
smart_calibration_force_trigger(true);  // 跳过安全检查

// 3. 恢复安全检查（标定后）
smart_calibration_set_time_window_enable(true);
smart_calibration_set_stability_check_enable(true);
smart_calibration_set_flood_prevention_enable(true);
```

### 误报水浸，需要紧急标定
```c
// 1. 临时禁用水浸防护
smart_calibration_set_flood_prevention_enable(false);

// 2. 等待环境稳定后标定
// （添加足够的采样数据）

// 3. 手动触发
smart_calibration_force_trigger(false);

// 4. 恢复水浸防护
smart_calibration_set_flood_prevention_enable(true);
```
