# 水位传感器 (MER-MCP1081-22-150) 协议总结

## 一、传感器规格

| 参数 | 规格 |
|------|------|
| **型号** | MER-MCP1081-22-150 |
| **测量原理** | 电容感应式（非接触） |
| **测量范围** | 0~126mm (0~12.6cm) |
| **档位数** | 7档 (0~6) |
| **每档分辨率** | 18mm (1.8cm) |
| **通信协议** | Modbus-RTU |
| **通信接口** | UART (9600bps, 8N1) |

---

## 二、蓝牙协议 (v1.5) - 监测数据上报

### 2.1 命令代码：105 (监测数据上报)

**报文方向**: 设备 → APP

**字段定义 (Body)**:

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | sensor_methane | string | 甲烷监测数值，包含%vol和%lel两种数据格式 |
| 2 | sensor_TEMP | int | 温度值，单位℃ |
| 3 | sensor_battery | string | 电池电压与电池电量百分比 |
| 4 | **water_level** | **string** | **水位传感器数据："档位,水位高度cm,温度"** |
| 5 | **water_level_cap** | **string** | **电容值："C0,C1,C2,C3,C4,C5,C6" (单位pF)** |

### 2.2 报文格式示例

```json
{
    "header": {
        "code": 105
    },
    "body": {
        "sensor_methane": "20,20",
        "sensor_TEMP": 50,
        "sensor_battery": "3.600,100",
        "water_level": "3,5.4,21.5",
        "water_level_cap": "12.35,15.28,18.92,22.15,25.67,28.34,30.12"
    },
    "result": 1
}
```

### 2.3 water_level 字段详解

**格式**: `"档位,水位高度cm,温度"`

| 位置 | 含义 | 类型 | 范围 | 示例值 | 说明 |
|------|------|------|------|--------|------|
| 第1位 | 液位档位 | 整数 | 0~6 | 3 | 0=空载, 6=满载 |
| 第2位 | 水位高度 | 浮点数 | 0.0~10.8 | 5.4 | 单位：cm，档位×1.8 |
| 第3位 | 传感器温度 | 浮点数 | -40~85 | 21.5 | 单位：℃ |

**示例**: `"3,5.4,21.5"` 表示：
- 档位：3
- 水位高度：5.4cm
- 温度：21.5℃

### 2.4 water_level_cap 字段详解

**格式**: `"C0,C1,C2,C3,C4,C5,C6"`

| 位置 | 含义 | 类型 | 范围 | 说明 |
|------|------|------|------|------|
| C0~C6 | 7个通道电容值 | 浮点数 | 0.00~99.99 | 单位：pF (皮法) |

**示例**: `"12.35,15.28,18.92,22.15,25.67,28.34,30.12"`
- C0 = 12.35 pF
- C1 = 15.28 pF
- C2 = 18.92 pF
- C3 = 22.15 pF
- C4 = 25.67 pF
- C5 = 28.34 pF
- C6 = 30.12 pF

## 三、4G协议 (v1.5) - 监测数据上报

### 3.1 命令代码：105 (监测数据上报)

**报文方向**: 设备 → 平台

**字段定义 (Header)**:

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | code | int | 命令代码105 |
| 2 | device_ID | string | 设备ID |

**字段定义 (Body)**:

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | sensor_methane | string | 甲烷监测数值，包含%vol和%lel两种数据格式 |
| 2 | sensor_TEMP | int | 温度值，单位℃ |
| 3 | sensor_battery | string | 电池电压与电池电量百分比 |
| 4 | collect_time | string | 数据收集时间 (格式: "YYYYMMDDHHmmss") |
| 5 | **water_level** | **string** | **水位传感器数据："档位,水位高度cm,温度"** |
| 6 | **water_level_cap** | **string** | **电容值："C0,C1,C2,C3,C4,C5,C6" (单位pF)** |

### 3.2 报文格式示例

```json
{
    "header": {
        "code": 105,
        "device_ID": "860123456789012"
    },
    "body": {
        "sensor_methane": "20,20",
        "sensor_TEMP": 50,
        "sensor_battery": "3.600,100",
        "collect_time": "20241204105400",
        "water_level": "3,5.4,21.5",
        "water_level_cap": "12.35,15.28,18.92,22.15,25.67,28.34,30.12"
    }

```

### 3.3 字段详解

**water_level** 和 **water_level_cap** 的格式与蓝牙协议完全一致（见2.3、2.4节）。

## 四、数据结构定义

### 4.1 代码中的数据结构 (ble_4g_protocol.h)

```c
typedef struct
{
    float pressure_hpa;              // 气压 hPa（用于水位检测）
    float water_depth_cm;            // 水深 cm（根据压力变化计算）
    float temperature_c;             // 温度 ℃
    float altitude_m;                // 海拔 m
    float battery_voltage;           // 电池电压 V
    uint8_t battery_percent;         // 电池电量 %
    
    // 水位传感器数据 (MER-MCP1081-22-150)
    uint8_t water_level_grade;       // 水位档位 (0~6)
    float water_level_temp_c;        // 水位传感器温度 ℃
    float water_level_height_cm;     // 水位高度 cm (档位×1.8)
    float water_level_cap[7];        // C0-C6电容值 (pF)
    
    char collect_time[16];           // 数据收集时间
    bool is_valid;                   // 数据有效性
} ble_4g_sensor_data_t;
```

### 4.2 档位与水位高度对照表

| 档位 | 水位高度 (cm) | 水位高度 (mm) | 状态描述 |
|------|---------------|---------------|----------|
| 0 | 0.0 | 0 | 空/极低 |
| 1 | 1.8 | 18 | 低 |
| 2 | 3.6 | 36 | 较低 |
| 3 | 5.4 | 54 | 中等 |
| 4 | 7.2 | 72 | 较高 |
| 5 | 9.0 | 90 | 高 |
| 6 | 10.8 | 108 | 满/最高 |

**计算公式**: `水位高度(cm) = 档位 × 1.8`

## 五、代码实?示例

### 5.1 JSON生成代码 (ble_4g_protocol.c 第566-584行)

```c
// 水位传感器数据 (MER-MCP1081-22-150 电子水尺)
// water_level: "档位,水位高度cm,温度" 格式
if (p_data->water_level_grade != 0xFF) {
    char water_level_str[48];
    snprintf(water_level_str, sizeof(water_level_str), "%d,%.1f,%.1f", 
             p_data->water_level_grade, 
             p_data->water_level_height_cm,
             p_data->water_level_temp_c);
    cJSON_AddStringToObject(body, "water_level", water_level_str);
    
    // water_level_cap: "C0,C1,C2,C3,C4,C5,C6" 电容值(pF)
    char cap_str[128];
    snprintf(cap_str, sizeof(cap_str), "%.2f,%.2f,%.2f,%.2f,%.2f,%.2f,%.2f",
             p_data->water_level_cap[0], p_data->water_level_cap[1],
             p_data->water_level_cap[2], p_data->water_level_cap[3],
             p_data->water_level_cap[4], p_data->water_level_cap[5],
             p_data->water_level_cap[6]);
    cJSON_AddStringToObject(body, "water_level_cap", cap_str);
}
```

### 5.2 数据有效性判断

- `water_level_grade == 0xFF`: 表示传感器读取失败或未连接，此时不上报水位传感器数据
- `water_level_grade == 0~6`: 有效档位值，上报完整的 `water_level` 和 `water_level_cap` 字段

## 六、协议一致性确认

### 6.1 蓝牙协议 vs 4G协议对比

| 项目 | 蓝牙协议 (v1.5) | 4G协议 (v1.5) | 一致性 |
|------|----------------|---------------|--------|
| **命令代码** | 105 | 105 | ? 一致 |
| **water_level 格式** | "档位,水位cm,温度" | "档位,水位cm,温度" | ? 一致 |
| **water_level_cap 格式** | "C0,C1,C2,C3,C4,C5,C6" | "C0,C1,C2,C3,C4,C5,C6" | ? 一致 |
| **档位范围** | 0~6 | 0~6 | ? 一致 |
| **水位高度单位** | cm | cm | ? 一致 |
| **电容值单位** | pF | pF | ? 一致 |
| **数据精度** | 档位=整数, 高度=1位小数, 温度=1位小数 | 档位=整数, 高度=1位小数, 温度=1位小数 | ? 一致 |
| **电容精度** | 2位小数 | 2位小数 | ? 一致 |

### 6.2 协议差异

| 项目 | 蓝牙协议 | 4G协议 | 说明 |
|------|----------|--------|------|
| **Header字段** | 无 device_ID | 有 device_ID | 4G需要设备ID标识 |
| **Body字段** | 无 collect_time | 有 collect_time | 4G需要采集时间戳 |
| **Result字段** | 有 result | 无 result | 蓝牙回文需要结果标志 |

## 七、重要注意事项

### 7.1 数据格式要求

1. **water_level 格式**:
   - 三个字段用 **逗号** 分隔
   - 档位：**整数** (0~6)
   - 水位高度：**浮点数**，保留 **1位小数**
   - 温度：**浮点数**，保留 **1位小数**

2. **water_level_cap 格式**:
   - 7个电容值用 **逗号** 分隔
   - 每个值：**浮点数**，保留 **2位小数**
   - 单位：**pF** (皮法)

### 7.2 数据范围约束

| 字段 | 最小值 | 最大值 | 无效值 |
|------|--------|--------|--------|
| water_level_grade | 0 | 6 | 0xFF |
| water_level_height_cm | 0.0 | 10.8 | - |
| water_level_temp_c | -40.0 | 85.0 | - |
| water_level_cap[0~6] | 0.00 | 99.99 | - |

### 7.3 协议兼容性

- 蓝牙协议和4G协议的 **water_level** 和 **water_level_cap** 字段 **完全一致**
- 无需为不同协议做格式转换
- 同一份数据可同时用于蓝牙和4G上报
