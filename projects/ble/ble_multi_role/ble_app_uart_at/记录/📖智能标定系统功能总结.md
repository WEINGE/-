# ? 智能基准标定系统 - 功能总结

## ? 功能概述

智能基准标定系统是一个自动维护气压基准的机制，用于应对大气压力的自然变化，确保水深测量的长期准确性。

### 核心问题

```
问题：大气压力会随时间变化（天气、季节）
影响：导致水深测量出现累积误差
解决：定期自动更新基准压力值
```

### 设计理念

```
自动化：无需人工干预
智能化：多条件综合判断
安全性：多层保护机制
适应性：应对各种环境变化
```

## ?? 核心参数配置

### 时间策略

```c
检查间隔：1小时
  每小时检查一次是否需要标定
  
最小间隔：3小时
  防止频繁标定，最快3小时一次
  
最大间隔：7天
  强制标定，确保baseline不会长期老化
```

### 标定触发条件

```c
漂移阈值：1.0 hPa (1 cm)
  当前压力与baseline偏差 > 1 cm → 需要标定
  
异常检测：10.0 hPa (10 cm)
  标定前后变化 > 10 cm → 认为异常，标定失败
```

### 环境稳定性要求

```c
压力方差：< 5.0 hPa?
  最近10分钟（10次采样）的压力波动
  允许缓慢变化，防止剧烈波动时标定
  
温度方差：< 999.0 hPa?（实际禁用）
  对温度变化不做严格限制
  
采样窗口：10次采样
  使用最近10分钟的数据计算方差
  
最少样本：8次
  至少需要8次采样才进行稳定性检查
```

### 水浸保护机制

```c
检测阈值：5.0 hPa (5 cm)
  压力差 > 5 cm → 触发水浸检测
  
连续确认：3次
  连续3分钟检测到才确认水浸
  防止瞬时波动误判
  
安全裕度：5.0 hPa (5 cm)
  压力差 < 5 cm → 重置水浸计数器
  允许小水浸时也能标定
```

### 时间窗口

```c
允许时段：0-23点（全天候）
  任何时间都可以标定
  不限制在特定时段
```

## ? 工作流程

### 系统启动

```
1. 开机初始化
   - 读取当前气压 (例如 1011 hPa)
   - 设置为初始baseline
   - 初始化智能标定系统
   
2. 启动定时器
   - 水位监测定时器：每1分钟
   - 标定检查定时器：每1小时
```

### 数据采集（每1分钟）

```
水位监测定时器触发:
  ↓
1. 开启传感器电源
  ↓
2. 读取传感器数据
   - WF5803F气压传感器
   - 水位传感器
  ↓
3. ? 同步数据到智能标定缓冲区
   smart_calibration_add_sample(pressure, temp, timestamp)
   → 维护最近10次数据（环形缓冲区）
  ↓
4. 水浸检测（简单阈值）
  ↓
5. 缓存数据供上报
  ↓
6. 关闭传感器电源
```

### 标定检查（每1小时）

```
标定检查定时器触发:
  ↓
1. 时间累加
   calibration_time_ms += 3600000 (1小时)
  ↓
2. 读取RTC时间
   获取当前小时（用于时间窗口检查）
  ↓
3. 调用智能标定调度
   smart_calibration_schedule(time, hour)
  ↓
4. 多条件检查（见下文）
  ↓
5. 满足条件 → 执行标定
   不满足 → 等待下次检查
```

## ? 标定触发条件（5层检查）

### 必须同时满足以下所有条件：

#### 1. 时间间隔检查 ?

```
条件A：从未标定过
  → 立即触发标定
  
条件B：距上次标定 ≥ 3小时
  → 可以标定
  
条件C：距上次标定 ≥ 7天
  → 强制标定（即使其他条件不满足）
  
条件D：基准漂移 > 1 cm
  → 需要标定
```

#### 2. 时间窗口检查 ?

```
当前时间在 0-23点
  → 通过（全天候）
```

#### 3. 环境稳定性检查 ?

```
最近10分钟数据:
  - 压力方差 < 5.0 hPa?
  - 温度方差 < 999.0 hPa?
  
目的：
  - 防止剧烈波动时标定
  - 允许缓慢变化时标定
  - 解决季节性气压变化问题
```

#### 4. 无水浸检查 ?

```
内部水浸检测:
  压力差 > 5 cm 且 连续3次
  → 阻止标定
  
主系统状态（可选）:
  device_water == 1
  → 阻止标定
```

#### 5. 基准合理性检查 ?

```
新baseline有效范围:
  900 hPa < baseline < 1100 hPa
  
变化幅度限制:
  abs(new_baseline - old_baseline) ≤ 10 hPa
```

## ? 标定执行过程

### 标定步骤

```
1. 记录旧基准
   old_baseline = 1011 hPa
   ↓
2. 执行标定
   wf5803f_set_baseline_pressure(0.0f)
   → 参数0表示使用当前读数作为新基准
   ↓
3. WF5803F内部操作
   current_pressure = 读取传感器()
   baseline = current_pressure
   ↓
4. 读取新基准
   new_baseline = wf5803f_get_baseline_pressure()
   例如: 1014 hPa
   ↓
5. 验证标定结果
   change = abs(1014 - 1011) = 3 hPa
   if (3 <= 10 && 900 < 1014 < 1100) {
       标定成功 ?
       更新 last_calibration_time
   } else {
       标定失败 ?
       恢复 old_baseline
   }
```

### 标定依据

```
假设：标定时刻无水浸（水深 = 0）
依据：当前时刻的气压读数
操作：将当前气压设为新的"0水深"基准
```

```

  - 不标定
  
T=3小时:
  - 气压缓慢上升到 1012 hPa
  - 水深显示 = 1 cm
  - 标定检查:
    ? 距上次 3小时
    ? 漂移 1 cm = 阈值
    ? 缓冲区有10次数据
    ? 环境稳定
    ? 无水浸
  - 执行标定 ?
  - baseline = 1012 hPa
  - 水深显示恢复 0 cm
```

### 场景2：真实水浸

```
T=0:
  - baseline = 1011 hPa
  - 无水
  
T=1小时:
  - 地下水位上升

  - 水深显示 = 10 cm ?

  - device_water = 1
  
T=3小时:
  - 标定检查触发
  - 检查内部水浸检测:
    pressure_delta = 10 hPa > 5 hPa
    连续3次确认
    → 确认水浸
  - 阻止标定 ?
  - baseline保持 1011 hPa
  - 水深继续显示 10 cm ?
```

### 场景3：长期水浸 + 季节变化

```
T=0:
  - baseline = 1011 hPa
  - 长期水浸 5 cm
  - pressure = 1016 hPa
  
T=3小时:
  - 标定检查
  - pressure_delta = 5 hPa = 5 hPa（检测阈值）
  - pressure_delta = 5 hPa = 5 hPa（安全裕度）
  - 计数器重置
  - 允许标定 ?
  - baseline = 1016 hPa
  - 水深 = 0 cm（实际仍有5cm水）
  
说明：
  - 系统假设当前无水
  - 5cm以下的长期水浸被接受
  - 更新baseline以适应气压变化

### 场景4：季节变化（无水浸）

```

  - baseline = 1011 hPa
  - 真实气压 = 1011 hPa
  
1个月后（春季）:
  - 真实气压缓慢上升到 1016 hPa

    1011 → 1012 → 1013 → 1014 → 1015 → 1016

  - 跟随气压变化 ?

## ?? 安全保护机制

### 1. 频率限制

```
最小间隔 3小时:
  - 防止频繁标定
  - 给系统稳定时间
  
最大间隔 7天:
  - 防止baseline长期老化
  - 强制更新
```

### 2. 水浸保护

```
内部检测:
  - 5cm以上触发
  - 连续3次确认
  - 5cm以下可重置
  
结合主系统:
  - 信任主系统水浸状态
  - 双重保护
```

### 3. 环境稳定性

```
防止标定时机:
  - 暴雨（气压剧烈波动）
  - 传感器异常
  - 数据不稳定
  
允许标定时机:
  - 缓慢气压变化
  - 季节性变化
  - 天气系统过境
```

### 4. 结果验证

```
标定后检查:
  - 变化 ≤ 10 cm
  - 范围 900-1100 hPa
  - 异常时恢复旧值
```
