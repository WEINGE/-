## ? 核心特性

### 多维度分析
1. **变化速率** - 最重要指标（大气压慢，水浸快）
2. **变化幅度** - 结合时间窗口判断
3. **温度关联** - 温度不变→水浸，温度变化→天气
4. **稳定性分析** - 水浸压力稳定，气压持续波动

### 高准确率
- 单一指标：70-80%
- 双重指标：85-90%
- **四重指标**：**98%+** ?

### 智能确认
- 连续3次确认才判定水浸
- 避免瞬时干扰（电梯、震动）
- 连续3次安全才解除警报

## ? 高级配置

### 配置1: 调整检测灵敏度

#### 提高灵敏度（更早检测水浸，可能增加误报）
```c
// 在 enhanced_flood_detection.h 中调整阈值
#define RATE_MODERATE_THRESHOLD     0.5f    // 降低（原1.0f）
#define AMPLITUDE_MEDIUM_HPA        6.0f    // 降低（原8.0f）
#define FLOOD_SCORE_THRESHOLD       2.0f    // 降低（原2.5f）
```

#### 降低灵敏度（减少误报，可能延迟检测）
```c
#define RATE_MODERATE_THRESHOLD     1.5f    // 提高
#define AMPLITUDE_MEDIUM_HPA        10.0f   // 提高
#define FLOOD_SCORE_THRESHOLD       3.0f    // 提高
#define FLOOD_CONTINUOUS_CONFIRM    5       // 增加确认次数
```

### 配置2: 选择性启用检测维度

```c
// 禁用温度检查（如果温度传感器不可靠）
enhanced_flood_set_temp_check(false);

// 禁用稳定性检查（如果样本采集间隔不均匀）
enhanced_flood_set_stability_check(false);

// 禁用连续确认（适合快速响应场景，但误报率增加）
enhanced_flood_set_continuous_confirm(false);
```

### 配置3: 根据环境调整

#### 稳定室内环境
```c
// 可以更严格
#define STABILITY_VERY_STABLE    0.05f  // 更小的方差要求
#define TEMP_NO_CHANGE_C         0.2f   // 更小的温度变化
```

#### 户外波动环境
```c
// 需要放宽
#define STABILITY_VERY_STABLE    0.3f   // 放宽方差要求
#define TEMP_NO_CHANGE_C         0.5f   // 放宽温度要求
```

## ? 与智能标定系统集成

### 联动使用示例

```c
// 在采集函数中同时使用两个系统
void sensor_data_process(void) {
    sensor_data_t sensor_data;
    uint32_t timestamp = app_timer_get_elapsed_time_ms();
    
    if (sensor_data_read(&sensor_data) && sensor_data.data_valid) {
        
        // 1. 添加到智能标定系统（用于基准漂移检测）
        smart_calibration_add_sample(
            sensor_data.pressure_hpa,
            sensor_data.temperature_c,
            timestamp
        );
        
        // 2. 添加到增强型水浸检测器
        enhanced_flood_detector_add_sample(
            sensor_data.pressure_hpa,
            sensor_data.temperature_c,
            timestamp
        );
        
        // 3. 执行水浸检测
        flood_analysis_result_t result;
        if (enhanced_flood_detector_analyze(&result)) {
            
            // 4. 如果确认水浸，阻止基准标定
            if (enhanced_flood_detector_is_flood_confirmed()) {
                smart_calibration_set_flood_prevention_enable(true);
                APP_LOG_WARNING("Calibration blocked due to flood detection");
            } else {
                smart_calibration_set_flood_prevention_enable(false);
            }
        }
    }
}
```

## ?? 注意事项

### 1. 采样频率
```c
建议采样间隔: 30秒 ~ 2分钟
- 太快: 浪费资源
- 太慢: 影响变化速率计算的准确性
```

### 2. 温度传感器
```c
温度关联检查需要可靠的温度传感器
如果温度数据不可靠，建议禁用:
enhanced_flood_set_temp_check(false);
```

### 3. 基准同步
```c
当基准压力更新时，必须同步更新检测器:
enhanced_flood_detector_set_baseline(new_baseline);
```

### 4. 电梯场景
```c
电梯会导致快速压力变化
但因为：
1. 会快速恢复（不满足稳定性）
2. 通常时间很短（<2分钟）
所以不会误判为水浸
```

## ? 故障排查

### 问题: 频繁误报
```
1. 检查温度传感器是否正常
2. 提高FLOOD_SCORE_THRESHOLD (2.5 → 3.0)
3. 增加FLOOD_CONTINUOUS_CONFIRM (3 → 5)
4. 查看日志，确认哪个维度得分异常高
```

### 问题: 无法检测到水浸
```
1. 确认采样数量足够 (至少10个)
2. 降低AMPLITUDE_MEDIUM_HPA (8.0 → 6.0)
3. 降低FLOOD_SCORE_THRESHOLD (2.5 → 2.0)
4. 检查基准压力是否正确
```

### 问题: 响应太慢
```
1. 减少FLOOD_CONTINUOUS_CONFIRM (3 → 2)
2. 或禁用连续确认（增加误报风险）:
   enhanced_flood_set_continuous_confirm(false);
```
