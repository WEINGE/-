# ? 降压情况下的标定分析

## ? 您的问题

**如果气压下降（降压），智能标定系统还能正常工作吗？**

---

## ? 答案：可以正常标定！

但行为与升压略有不同，让我详细分析。

## ? 降压场景分析

### 场景：气压从1011降到1008 hPa

```
T=0 (初始):
  baseline = 1011 hPa
  实际气压 = 1011 hPa
  水深显示 = 0 cm
  
T=1天后 (气压下降):
  baseline = 1011 hPa（未标定）
  实际气压 = 1008 hPa
  
  计算:
  water_depth = (1008 - 1011) * 1.0
              = -3 cm
  
  显示:
  water_depth = 0 cm（负值保护）
  
  问题:
  - 水深显示为0（被保护了）
  - 但实际应该标定
```

## ? 标定触发条件检查

### 1. 漂移检测 ?

```c
// 代码逻辑
float drift = abs(current_avg - baseline);
            = abs(1008 - 1011)
            = abs(-3)
            = 3 hPa

if (drift > 1.0) {  // 阈值1cm
    需要标定 ?
}
```

**结果**: ? **可以检测到降压漂移**
- 使用绝对值abs()
- 不管升压还是降压
- 只要偏差 > 1 cm就触发

---

### 2. 时间间隔 ?

```
距离上次标定 3小时
→ 满足最小间隔 ?
```

---

### 3. 环境稳定性 ?

```
降压通常是缓慢的:
  - 方差计算不区分升降
  - 只要变化平缓就能通过
  
如果突然降压（如台风）:
  - 方差会很大
  - 不会标定（正确行为）
```

---

### 4. 水浸检测 ?（关键）

```c
// 代码逻辑
float delta = current_pressure - baseline;
            = 1008 - 1011
            = -3 hPa

// 检测水浸（正向）
if (delta > 5.0) {  // 增压检测
    flood_counter++;  // 不会执行（-3 < 5）
}

// 安全重置
if (delta < 5.0) {  // 安全裕度
    flood_counter = 0;  // 会执行（-3 < 5）?
}

结果:
  flood_counter = 0
  不会阻止标定 ?
```

**结果**: ? **降压不会触发水浸检测**
- 水浸检测只检测正向（压力增加）
- 降压不会被误判为水浸
- 可以正常标定
