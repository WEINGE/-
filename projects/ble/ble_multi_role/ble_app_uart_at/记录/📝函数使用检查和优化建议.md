### 3. ?? 时间戳获取（需要优化）

#### 当前使用（可能不够精确）
```c
(uint32_t)(sdk_rtc_counter_get() / 32)  // RTC计数器转毫秒
```

#### 问题分析
```
sdk_rtc_counter_get():
  返回: RTC计数器值
  频率: 32768 Hz
  转换: counter / 32.768 ≈ 毫秒

问题:
  1. 除以32不精确（应该是32.768）
  2. 计数器可能溢出（uint32_t）
  3. 原有代码不使用这个方法
```

#### ? 优化建议：使用静态计数器

**原有代码的做法**（water_level_sensor.c第509行）:
```c
static uint32_t counter = 0;
p_data->timestamp = counter++;  // 简单递增计数器
```

**为什么这样更好？**
```
优点:
  ? 简单可靠
  ? 不会溢出循环
  ? 只需要相对时间差
  ? 增强型检测只关心时间间隔，不需要绝对时间
  
代码示例:
  static uint32_t sample_counter = 0;
  enhanced_flood_detector_add_sample(
      pressure,
      temperature,
      sample_counter++  // 每次递增1，单位是"采样次数"
  );
```

## ? 推荐的优化方案

### 选项1: 使用静态计数器（推荐）?

**优点**: 
- 简单可靠
- 与原有代码模式一致
- 不依赖系统时钟
- 适合检测速率变化

**实现**:
```c
// 在 ble_4g_protocol.c 顶部添加
static uint32_t g_sample_timestamp_counter = 0;

// 在 water_monitor_timer_handler 中使用
enhanced_flood_detector_add_sample(
    sensor_reading.pressure_hpa,
    sensor_reading.temperature_c,
    g_sample_timestamp_counter++  // 每分钟+1
);

// 在 calibration_check_timer_handler 中使用
static uint32_t g_calibration_check_counter = 0;
bool calibration_attempted = smart_calibration_schedule(
    g_calibration_check_counter++,  // 每小时+1
    current_hour
);
```

**说明**:
```
g_sample_timestamp_counter:
  - 每分钟递增1次（water_monitor_timer触发时）
  - 60次 = 1小时
  - 1440次 = 1天
  - 单位是"分钟"

增强型检测使用:
  - 计算速率时: 差值 = 时间间隔（分钟）
  - 10次采样 = 10分钟
  - 完全足够用于速率分析
```

## ? 具体修改步骤

### Step 1: 添加静态变量

在 `ble_4g_protocol.c` 的全局变量区（约第110行附近）添加:
```c
// 时间戳计数器（用于增强型检测和智能标定）
static uint32_t g_sample_timestamp_counter = 0;       // 每分钟+1
static uint32_t g_calibration_check_counter = 0;      // 每小时+1
```

### Step 2: 修改 water_monitor_timer_handler

将：
```c
enhanced_flood_detector_add_sample(
    sensor_reading.pressure_hpa,
    sensor_reading.temperature_c,
    (uint32_t)(sdk_rtc_counter_get() / 32)
);
```

改为：
```c
enhanced_flood_detector_add_sample(
    sensor_reading.pressure_hpa,
    sensor_reading.temperature_c,
    g_sample_timestamp_counter++  // 每分钟递增
);
```

### Step 3: 修改 calibration_check_timer_handler

将：
```c
bool calibration_attempted = smart_calibration_schedule(
    (uint32_t)(sdk_rtc_counter_get() / 32),
    current_hour
);
```

改为：
```c
bool calibration_attempted = smart_calibration_schedule(
    g_calibration_check_counter++ * 60 * 60 * 1000,  // 转换为毫秒
    current_hour
);
```
