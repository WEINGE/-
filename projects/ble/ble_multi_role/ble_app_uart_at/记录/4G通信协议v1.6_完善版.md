## 2. 报文Code编码

| Code | 业务类型 |
|------|----------|
| 102 | 设备信息上报 |
| 103 | 状态信息上报 |
| 104 | 当前设置参数上报 |
| 105 | 监测数据上报 |
| 106 | 检测周期设置 |
| 107 | 上报周期设置 |
| 108 | 温度及水深报警阈值设置 |
| 110 | 水浸报警阈值设置（保留） |
| 120 | 查询设置变更 |

**说明**：4G协议不包含Code 101查询指令，设备主动上报数据到平台

### 3.9 查询设置变更

**Header**

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | code | int | 命令代码120 |
| 2 | device_ID | string | 设备ID（IMEI） |

**报文方向**：设备->平台

**报文格式**：
```json
{
  "header": {
    "code": 120,
    "device_ID": "865123456789012"
  }
}
```

**说明**：
- 设备在上传数据后发送此查询，询问平台是否有参数设置变更
- 如果平台有设置变更，会使用Code 106-110的设置命令进行下发
- 设备ID为"FFFFFFFFFFFF"表示广播地址，平台使用此ID将对所有在线设备执行设置
- 设备在接收最后一条设置命令后10秒内无其他设置命令则再次休眠

## 4. 服务器参数及上传逻辑

### 4.1 MQTT连接参数

**默认MQTT参数**：
- 地址：`mqtt://emqx.changyg.top`
- 端口：`23622`
- 用户名：`ThingsBoard`
- 密码：`ctkjThingsBoard`
- MQTT客户端ID：使用设备ID（IMEI）
- 设备上报主题：`/methane_sensor/test/report`
- 指令下发主题：`/methane_sensor/test/command`

**说明**：
- 以上参数可通过蓝牙协议Code 111进行配置修改
- Keepalive默认值为30秒，在1.5倍Keepalive时间内无数据包则认为连接断开

### 4.2 数据上传逻辑

1. **正常上报流程**：
   - 设备在达到设定时间间隔后唤醒启动
   - 上传设备信息（Code 102）
   - 上传当前设置参数（Code 104）
   - 上传监测数据（Code 105）和状态信息（Code 103）
   - 发送查询设置变更命令（Code 120）
   - 等待10秒接收平台可能下发的设置命令
   - 若无设置命令或超过10秒，再次休眠

2. **水浸报警上报**：
   - 检测到水深超过阈值时立即唤醒
   - 立即上传Code 105和Code 103数据
   - 进入水浸模式：采集间隔3分钟，上传间隔30分钟
   - 水深恢复正常后退出水浸模式，恢复原设置

3. **数据累积上传**：
   - 支持采集间隔小于上传间隔的场景（如1分钟采集，30分钟上传）
   - 缓冲区最多存储30条采集数据
   - 上传时一次性上传所有累积的数据
   - 上传成功后清空缓冲区

### 4.3 广播设置

平台使用设备ID `FFFFFFFFFFFF` 下发设置命令时，所有在线设备都会响应该设置。

### 4.4 电源管理

设备采用低功耗设计：
- 休眠期间关闭4G模块和传感器电源
- 唤醒时先开启电源，等待模块稳定后再进行数据采集和上传
- 上传完成后关闭电源进入休眠

## 5. 传感器说明

本系统使用以下传感器：

1. **WF5803F气压传感器**：
   - 用途：水位监测，通过气压变化计算水深
   - 输出数据：气压（hPa）、温度（℃）、海拔（m）
   - 水深计算：1cm水深≈0.98hPa压力变化

2. **MER-MCP1081-22-150电子水尺**：
   - 用途：辅助水位检测
   - 输出数据：档位（0-6）、水位高度（cm）、温度（℃）、7个电容值（pF）
   - 每档约1.8cm水位高度

3. **电池电压监测**：
   - 实时监测电池状态
   - 输出数据：电压（V）、电量百分比（%）

## 6. 智能基准压力标定系统

系统内置智能基准压力标定功能：

1. **自动标定**：
   - 启动后约2小时自动完成基准压力标定
   - 使用卡尔曼滤波器平滑压力数据
   - 环境稳定性检测确保标定准确性

2. **水浸检测**：
   - 基于标定好的基准压力计算水深
   - 水深超过阈值（默认5cm）触发报警
   - 自动进入水浸模式进行高频监测

## 7. 注意事项

1. **设备ID**：必须使用4G模块的IMEI作为设备ID
2. **时间格式**：collect_time使用12位数字格式"YYYYMMDDHHmm"
3. **坐标格式**：经纬度格式为"经度,纬度"，例如"113.253342,25.684351"
4. **信号强度**：4G信号值范围0-31，越大越好，一般大于17能够正常稳定工作
5. **防盗判断**：定位坐标与安装坐标差距在半径20m内视作正常
6. **水深阈值**：默认5cm，可通过Code 108设置
7. **JSON格式**：所有报文必须是有效的JSON格式
8. **字段命名**：严格按照协议定义的字段名，区分大小写
