# ? 智能标定系统参数用途详解

## ?? 重要区分：不同参数用于不同目的！

### 参数分类

```c
// === 组1: 标定触发条件 ===
#define BASELINE_DRIFT_THRESHOLD_HPA      1.0f   // 决定是否需要标定
#define BASELINE_ABNORMAL_DELTA_HPA       10.0f  // 判断标定结果是否异常

// === 组2: 水浸保护机制 ===  
#define FLOOD_DETECTION_DELTA_HPA         8.0f   // 触发水浸检测
#define FLOOD_CONTINUOUS_COUNT            3      // 连续确认次数
#define FLOOD_SAFE_DELTA_HPA              5.0f   // 安全裕度
```

---

## ? 详细用途说明

### 1. BASELINE_DRIFT_THRESHOLD_HPA = 1.0f

**用途**: 决定是否需要标定

```c
// 在 smart_calibration_is_needed() 中

float drift = abs(当前压力平均值 - baseline);

if (drift > 1.0 hPa) {
    // 漂移超过1cm，需要标定
    return true;
}
```

**作用**:
```
? 判断何时触发标定
? 1 hPa = 1 cm漂移
? 您设置为1.0 = 高精度，1cm误差就标定

示例:
  baseline = 1011 hPa
  当前平均 = 1012.5 hPa
  drift = 1.5 hPa > 1.0
  → 需要标定 ?
```

**不判断水浸！仅判断是否需要标定！**

---

### 2. BASELINE_ABNORMAL_DELTA_HPA = 10.0f

**用途**: 验证标定结果是否合理

```c
// 在标定执行后

float new_baseline = 读取新基准();
float old_baseline = 旧基准();
float change = abs(new_baseline - old_baseline);

if (change > 10.0 hPa) {
    // 变化太大，认为异常
    // 可能是传感器故障或有水浸
    标定失败，恢复旧基准();
}
```

**作用**:
```
? 防止异常标定
? 标定前后差异 > 10 hPa 认为不正常

示例:
  旧baseline = 1011 hPa
  标定后 = 1022 hPa (差11 hPa)
  change = 11 > 10
  → 认为异常，标定失败 ?
  → 可能有水浸或传感器故障
```

**不判断水浸！但用异常变化来推断可能有问题！**

---

### 3. FLOOD_DETECTION_DELTA_HPA = 8.0f

**用途**: 智能标定系统内部的水浸检测

```c
// 在 smart_calibration_detect_possible_flood() 中

float delta = 当前压力 - baseline;

if (delta > 8.0 hPa) {
    // 触发水浸检测
    flood_counter++;
}
```

**作用**:
```
? 这是真正的水浸检测阈值！
? 用于防止在有水时标定

示例:
  baseline = 1011 hPa
  当前压力 = 1020 hPa
  delta = 9 hPa > 8.0
  → 触发水浸检测计数器
```

**这个才是判断水浸的！**

---

### 4. FLOOD_CONTINUOUS_COUNT = 3

**用途**: 需要连续检测多少次才确认水浸

```c
if (delta > 8.0 hPa) {
    flood_counter++;
}

if (flood_counter >= 3) {
    // 连续3次检测到，确认水浸
    return true;  // 阻止标定
}
```

**作用**:
```
? 防止误判
? 需要连续3分钟（3次采样）才确认

示例:
  T=0: delta=9 hPa, counter=1
  T=1: delta=9 hPa, counter=2  
  T=2: delta=9 hPa, counter=3
  → 确认水浸 ?
```

**配合水浸检测使用！**

---

### 5. FLOOD_SAFE_DELTA_HPA = 5.0f

**用途**: 判断何时重置水浸计数器

```c
if (delta < 5.0 hPa) {
    // 压力差小于5cm，认为安全
    flood_counter = 0;  // 重置
}
```

**作用**:
```
? 判断水浸消退
? 允许恢复标定功能

示例:
  之前: counter=3（水浸状态）
  现在: delta=4 hPa < 5.0
  → flood_counter=0
  → 允许标定 ?
```

**判断水浸是否消退！**

## ? 总结对比

### 哪个判断水浸？

```
FLOOD_DETECTION_DELTA_HPA = 8.0f  ← 这个！
  作用: 触发水浸检测
  判断: delta > 8 → 可能有水浸
  
FLOOD_CONTINUOUS_COUNT = 3  ← 这个！
  作用: 连续确认次数
  判断: 连续3次 > 8 → 确认水浸
  
FLOOD_SAFE_DELTA_HPA = 5.0f  ← 这个！
  作用: 重置条件
  判断: delta < 5 → 水浸消退
```

### 哪个不判断水浸？

```
BASELINE_DRIFT_THRESHOLD_HPA = 1.0f  ← 不判断水浸！
  作用: 决定是否需要标定
  判断: 漂移 > 1 → 需要标定
  
BASELINE_ABNORMAL_DELTA_HPA = 10.0f  ← 不判断水浸！
  作用: 验证标定结果
  判断: 标定变化 > 10 → 异常
```

## ? 完整工作流程

### 标定触发流程

```
1. 检查是否需要标定:
   if (drift > 1.0 hPa) {  ← DRIFT_THRESHOLD
       需要标定
   }
   
2. 检查是否有水浸（阻止标定）:
   if (delta > 8.0 hPa) {  ← FLOOD_DETECTION_DELTA
       flood_counter++
   }
   if (flood_counter >= 3) {  ← CONTINUOUS_COUNT
       确认水浸，阻止标定
   }
   
3. 执行标定
   
4. 验证标定结果:
   if (abs(new - old) > 10.0) {  ← ABNORMAL_DELTA
       标定失败，恢复旧值
   }
```

### 水浸检测流程

```
每次采样:
  delta = pressure - baseline
  
  if (delta > 8.0) {  ← DETECTION触发
      flood_counter++
  }
  
  if (delta < 5.0) {  ← SAFE重置
      flood_counter = 0
  }
  
  if (flood_counter >= 3) {  ← COUNT确认
      水浸确认
  }
```
