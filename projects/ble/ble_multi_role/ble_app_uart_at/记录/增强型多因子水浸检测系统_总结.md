## ? 关键技术亮点

### 1. 变化速率是最重要的指标 ?

```
大气压: 0.017 ~ 0.033 hPa/分钟（缓慢）
水浸:   2 ~ 5 hPa/分钟（快速）

差异: 100倍！
```

### 2. 温度关联分析非常有效 ??

```
天气变化: 压力↑ + 温度显著变化
水浸:     压力↑ + 温度几乎不变

关键: 水温变化远小于气温变化
```

### 3. 连续确认避免瞬时干扰 ?

```
瞬时干扰(电梯/震动): 检测到1-2次后恢复
真实水浸:           连续检测到 ≥3次

策略: 连续3次确认才判定
```

### 4. 稳定性分析锁定水浸特征 ?

```
水浸特征: 快速上升 → 压力恒定(方差<0.1)
气压特征: 缓慢变化 → 持续波动(方差>0.5)
```

## ?? 重要提示

### 必须启用温度传感器
```
温度关联分析是区分气压和水浸的关键
如果没有温度传感器，准确率会降到80-85%
建议：
  - 有温度传感器: 全部启用（98%+准确率）
  - 无温度传感器: 禁用温度检查（85%准确率）
    enhanced_flood_set_temp_check(false);
```

### 采样频率建议
```
推荐: 30秒 ~ 2分钟
  - 太快(如每秒): 浪费资源，无意义
  - 太慢(如10分钟): 影响速率计算
  - 最佳: 1分钟
```

### 基准同步很重要
```
当智能标定系统更新基准压力时
必须同步更新水浸检测器的基准:
  enhanced_flood_detector_set_baseline(new_baseline);
```
