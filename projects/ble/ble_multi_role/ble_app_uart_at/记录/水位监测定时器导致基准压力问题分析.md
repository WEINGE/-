# 水位监测定时器导致基准压力问题 - 完整修复

## ?? 问题根源（已找到并修复）

### 真正的罪魁祸首

**`sensor_data_init()` 函数中设置基准压力**（文件：`sensor_data_parser.c` 第70行）

```c
bool sensor_data_init(void)
{
    // ... 初始化代码 ...
    
    // ? 问题代码：每次初始化都设置基准压力
    wf5803f_set_baseline_pressure(0.0f);
    
    return true;
}
```

### 问题调用链

```
水位监测定时器（每1分钟触发一次）
  ↓
water_monitor_timer_handler()
  ↓
sensor_data_init()  ← 传感器上电后初始化
  ↓
wf5803f_set_baseline_pressure(0.0f)  ← ? 每次都重新设置基准！
```

**结果**：基准压力被水位监测定时器每1分钟更新一次，导致基准值不断变化。

## ? 完整修复方案

### 修复1：移除 `sensor_data_init()` 中的基准设置 ? **核心修复**

**文件**：`sensor_data_parser.c`

**修改前**：
```c
bool sensor_data_init(void)
{
    // ... 初始化代码 ...
    
    s_sensor_initialized = true;
    APP_LOG_INFO("WF5803F sensor initialized successfully");
    
    // ? 每次初始化都设置基准（被水位监测定时器频繁调用）
    wf5803f_set_baseline_pressure(0.0f);
    
    return true;
}
```

**修改后**：
```c
bool sensor_data_init(void)
{
    // ... 初始化代码 ...
    
    s_sensor_initialized = true;
    APP_LOG_INFO("WF5803F sensor initialized successfully");
    
    // ? 修复：不在这里设置基准压力！
    // 原因：sensor_data_init() 会被水位监测定时器频繁调用（每1分钟）
    // 每次调用都会重新设置基准压力，导致基准压力被错误更新
    // 基准压力应该由 ble_4g_protocol_init() 或首次采集时设置
    // 已移除：wf5803f_set_baseline_pressure(0.0f);
    
    return true;
}
```

### 修复2：移除 `wf5803f_detect_flood()` 中的自动设置

**文件**：`wf5803f_driver.c`

**修改前**：
```c

    if (!s_baseline_set) {

```

## ? 为什么之前没发现？

第一次修复时，我只检查了：
- ? `wf5803f_detect_flood()` 中的自动设置 ← 修复了
- ? `ble_4g_protocol.c` 中的采集定时器 ← 检查了，但保留了（合理）

但**遗漏了**：
- ? `sensor_data_init()` 中的设置 ← ? 这才是真正的问题！

原因：
- `sensor_data_init()` 看起来是一个"初始化函数"
- 通常认为初始化函数只在启动时调用一次
- 但实际上，水位监测定时器**每次读取前都要重新初始化传感器**（因为传感器会断电省电）
- 所以 `sensor_data_init()` 被频繁调用，导致基准被频繁设置

1. 移除 `sensor_data_init()` 中的设置（? 核心）
2. 移除 `wf5803f_detect_flood()` 中的自动设置

**基准压力现在只在上电初始化时设置，之后保持不变！**
