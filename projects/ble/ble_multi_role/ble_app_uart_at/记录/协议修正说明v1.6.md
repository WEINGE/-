# 通信协议v1.6修正说明

## 概述

根据实际代码(`ble_protocol.c`, `ble_4g_protocol.c`, `shared_params.h`等)对蓝牙和4G通信协议文档进行了全面完善，主要修正如下：

## 主要修正内容

### 1. 传感器类型更正

**原文档**：激光气体传感器（甲烷检测）  
**实际代码**：水位监测传感器系统

**涉及的传感器**：
- WF5803F气压传感器（用于水位检测）
- MER-MCP1081-22-150电子水尺（辅助水位检测）
- 电池电压监测模块

### 2. 数据字段修正

#### 3.5 监测数据上报 (Code 105)

**原字段**：
```json
{
  "sensor_methane": "20,20",  // 甲烷浓度
  "sensor_TEMP": 50,
  "sensor_battery": "3.600,100"
}
```

**实际字段**（根据代码）：
```json
{
  "sensor_pressure": "1013.25,0.0",  // 气压hPa,水深cm
  "sensor_TEMP": 25,  // 温度℃
  "sensor_battery": "3.600,100",  // 电压V,电量%
  "water_level": "3,5.4,24.5",  // （可选）档位,高度cm,温度℃
  "water_level_cap": "12.34,23.45,..."  // （可选）7个电容值pF
}
```

**代码位置**：`ble_protocol.c` 行404-443

### 3. 阈值设置修正

#### 3.8 温度及水深阈值设置 (Code 108)

**原描述**：甲烷及温度报警阈值设置  
**实际描述**：温度及水深报警阈值设置

**原字段**：
```json
{
  "methane_threshold_set": 20,  // 甲烷阈值
  "TEMPH_threshold_set": 50,
  "TEMPL_threshold_set": -20
}
```

**实际字段**（根据代码）：
```json
{
  "water_depth_threshold_cm_set": 5.0,  // 水深阈值cm
  "TEMPH_threshold_set": 50,  // 高温阈值℃
  "TEMPL_threshold_set": -20  // 低温阈值℃
}
```

**代码位置**：
- `ble_protocol.c` 行638-642
- `shared_params.h` 行17（water_depth_threshold_cm定义）

### 4. 数据类型修正

#### 水深阈值类型变更

**原类型**：int  
**实际类型**：float

**原因**：需要支持小数精度的水深阈值（如2.5cm）

**代码位置**：`shared_params.h` 行17

### 5. 新增命令

#### Code 123 - 服务器地址查询

**状态**：在原v1.5文档中有提及但描述不完整  
**完善内容**：
- 详细的请求和响应格式
- 返回完整的服务器配置（包括pub_topic和sub_topic）

**代码位置**：`ble_protocol.c` 行64（宏定义）

### 6. 4G协议特殊字段

#### Code 105 增加时间戳字段

**4G协议特有字段**：
```json
{
  "collect_time": "202601141530"  // YYYYMMDDHHmm
}
```

**代码位置**：
- `ble_4g_protocol.c` 行533-634
- `4g_time_utils.c`（时间处理）

### 7. Header结构差异

#### 蓝牙协议
```json
{
  "header": {
    "code": 105
  }
}
```

#### 4G协议  
```json
{
  "header": {
    "code": 105,
    "device_ID": "865123456789012"  // 4G协议header中包含设备ID
  }
}
```

**代码位置**：  
- 蓝牙：`ble_protocol.c` 行400
- 4G：`ble_4g_protocol.c` 行544-547

### 8. Code编码表补充

**新增/修正**：
- Code 112：由"新增服务器地址设置"改为"保留"
- Code 123：服务器地址查询（补充详细说明）
- Code 120：查询设置变更（4G协议专用）

### 9. 设备ID说明

**完善说明**：
- 优先使用4G模块的IMEI作为device_ID
- 无法获取IMEI时降级使用MAC地址
- 广播地址"FFFFFFFFFFFF"用于批量设置

**代码位置**：`ble_protocol.c` 行485-493

### 10. 水浸模式逻辑

**新增说明**：
- 正常模式：按设定周期采集和上报
- 水浸模式：检测到水深超阈值时自动切换
  - 采集间隔：3分钟
  - 上报间隔：30分钟
- 水深恢复正常后自动退出水浸模式

**代码位置**：`ble_4g_protocol.c` 行138-142

### 11. 智能基准压力标定

**新增说明**：
- 自动标定时长：约2小时
- 使用卡尔曼滤波平滑数据
- 环境稳定性检测
- 水深计算基于标定的基准压力

**代码位置**：`smart_baseline_calibration.c`

### 12. MQTT配置详细参数

**新增详细说明**：
- 服务器地址和端口
- 用户名和密码
- 发布/订阅主题
- Keepalive参数（30秒）
- 客户端ID使用规则

**代码位置**：
- `4G通信协议v1.5.md` 行446-454
- DTU配置相关代码
