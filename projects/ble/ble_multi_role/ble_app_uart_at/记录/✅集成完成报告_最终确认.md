```

典型一天气压变化:
  早上:  1013 hPa
  中午:  1008 hPa (-5 hPa)
  傍晚:  1015 hPa (+2 hPa)
  夜晚:  1011 hPa (-2 hPa)

累积误差: 可达 ±10cm
但这不是真实水位变化！而是大气压波动！
```

系统现在能区分：
- ? **大气压自然波动** → 缓慢变化（0.03 hPa/分钟），温度同时变化
- ?? **真实水浸事件** → 快速变化（2-5 hPa/分钟），温度几乎不变

#### 2?? **4维度综合判断**
```
评分维度:
1. 变化速率: 大气压慢，水浸快  (权重?????)
2. 变化幅度: 结合时间判断      (权重????)
3. 温度关联: 气压变温度跟随    (权重???)
4. 稳定性:   水浸后压力恒定    (权重???)

总分 ≥ 2.5/4.0 → 确认水浸
总分 < 2.5/4.0 → 大气压波动（忽略）
```
