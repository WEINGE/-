# ? 智能标定系统的水浸检测参数详解

## ? 三个参数的含义

### 1. `FLOOD_DETECTION_DELTA_HPA = 8.0f`

**含义**: 水浸检测阈值

```c
#define FLOOD_DETECTION_DELTA_HPA  8.0f  // 8 hPa ≈ 8 cm 水深
```

**作用**:
```
当前压力 - baseline > 8 hPa
→ 可能有水浸
→ 触发水浸检测计数器
```

**理解**:
```
这是智能标定系统内部的水浸保护机制
不是主要的水浸检测（主要检测在ble_4g_protocol.c中）
用于防止在有水浸时错误标定
```

---

### 2. `FLOOD_CONTINUOUS_COUNT = 3`

**含义**: 连续检测确认次数

```c
#define FLOOD_CONTINUOUS_COUNT  3  // 需要连续3次确认
```

**作用**:
```
连续3次检测到 delta > 8 hPa
→ 确认为水浸
→ 阻止标定执行
```

**为什么需要连续确认？**
```
防止误判:
  - 单次读数可能有误差
  - 短暂波动不应认为是水浸
  - 连续3次更可靠

配合采样间隔:
  - 每1分钟采样一次
  - 连续3次 = 3分钟持续
  - 确保不是瞬时扰动
```

---

### 3. `FLOOD_SAFE_DELTA_HPA = 2.0f`

**含义**: 安全裕度阈值

```c
#define FLOOD_SAFE_DELTA_HPA  2.0f  // 2 hPa ≈ 2 cm
```

**作用**:
```
当前压力 - baseline < 2 hPa
→ 认为安全（没有水浸风险）
→ 可以重置水浸计数器
```

**理解**:
```
这是"退出水浸状态"的条件
如果压力恢复到接近基准（< 2 hPa）
→ 认为水已经消退
→ 允许后续标定
```

---

## ? 工作流程示例

### 场景1: 正常无水

```
T=0分:  
  pressure - baseline = 0.5 hPa
  < 2 hPa (SAFE) → 安全
  < 8 hPa (FLOOD) → 无水浸
  flood_counter = 0
  
T=1分:
  pressure - baseline = 1.0 hPa
  < 2 hPa (SAFE) → 安全
  < 8 hPa (FLOOD) → 无水浸
  flood_counter = 0
  
结果: 正常运行，可以标定
```

---

### 场景2: 真实水浸（10cm）

```
T=0分:
  pressure - baseline = 10 hPa
  > 8 hPa (FLOOD阈值) → 检测到！
  flood_counter = 1

T=1分:
  pressure - baseline = 10 hPa
  > 8 hPa → 再次检测到
  flood_counter = 2

T=2分:
  pressure - baseline = 10 hPa
  > 8 hPa → 第三次确认
  flood_counter = 3 = CONTINUOUS_COUNT
  
  → 确认水浸！
  → 阻止标定
  
结果: 不会在有水时标定 ?
```

---

### 场景3: 水浸后消退

```
正在水浸中:
  flood_counter = 3（已确认水浸）
  
T=10分:
  水开始消退
  pressure - baseline = 5 hPa
  > 2 hPa (SAFE) → 还不够安全
  继续保持水浸状态
  
T=20分:
  水继续消退
  pressure - baseline = 1.5 hPa
  < 2 hPa (SAFE) → 安全！
  flood_counter = 0（重置）
  
结果: 可以恢复标定功能 ?
```

---

### 场景4: 瞬时波动（误判防护）

```
T=0分:
  pressure - baseline = 9 hPa（瞬时干扰）
  > 8 hPa → 检测到
  flood_counter = 1

T=1分:
  pressure - baseline = 1 hPa（恢复正常）
  < 2 hPa (SAFE) → 安全
  flood_counter = 0（重置）
  
T=2分:
  正常
  flood_counter = 0
  
结果: 没有误判为水浸 ?
```

## ? 参数之间的关系

### 三个阈值的层次

```
SAFE (2 hPa)                FLOOD (8 hPa)
    ↓                            ↓
|------|------------------------|---------|
0 hPa  2 hPa                  8 hPa    ∞

区间1 (0-2):   安全区（可以标定）
区间2 (2-8):   观察区（不确定）
区间3 (8+):    水浸区（连续3次确认后阻止标定）
```

### 连续确认的意义

```
单次检测 > 8 hPa:
  → flood_counter++
  → 还不确定

连续3次 > 8 hPa:
  → flood_counter = 3
  → 确认水浸
  → 阻止标定
```

## ? 总结

### 三个参数的作用

```
FLOOD_DETECTION_DELTA_HPA (8.0f):
  → 触发水浸检测的阈值
  → 8cm以上开始计数

FLOOD_CONTINUOUS_COUNT (3):
  → 需要连续确认的次数
  → 防止误判

FLOOD_SAFE_DELTA_HPA (2.0f):
  → 安全区阈值
  → 2cm以内认为无水浸风险
```

### 工作原理

```
1. 每次采样检查压力差
2. > 8 hPa → counter++
3. < 2 hPa → counter = 0
4. counter = 3 → 确认水浸
5. 确认水浸时 → 阻止标定
```
