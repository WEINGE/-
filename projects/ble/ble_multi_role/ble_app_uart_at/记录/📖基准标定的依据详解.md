# ? 智能基准标定的依据详解

## ? 基准标定是什么？

**基准压力**: 设备开机时无水状态下的大气压力值

**为什么需要标定**: 
- 大气压力会随天气、季节缓慢变化
- 长时间运行后，开机时的基准可能不再准确
- 需要定期更新基准，保持水深测量准确

---

## ? 标定的依据：使用当前压力作为新基准

### 核心逻辑

**标定时的操作**:
```c
// smart_baseline_calibration.c 第285行
wf5803f_set_baseline_pressure(0.0f);  // 参数0表示：使用当前读数
```

**这意味着**:
```
标定 = 假设当前没有水
     = 把当前气压读数设为新的"0水深"基准
```

---

## ? 标定依据的5层检查

智能标定不是随便执行的，必须同时满足5个条件，确保"当前确实没有水"：

### 1?? 时间间隔检查 ?

**目的**: 防止频繁标定

```c
最小间隔: 6小时
最大间隔: 7天（强制标定）

检查逻辑:
if (time_since_last >= 6小时 && time_since_last <= 7天) {
    通过 ?
}
```

**意义**: 
- 6小时内不标定 → 给系统稳定时间
- 超过7天强制标定 → 防止基准长期漂移

---

### 2?? 时间窗口检查 ?

**目的**: 选择稳定时段

```c
当前配置: 0-23点（全天候）

检查逻辑:
if (current_hour >= 0 && current_hour <= 23) {
    通过 ?
}
```

**意义**: 
- 原本设计在凌晨2-5点（大气稳定）
- 您修改为全天候（0-23点）

---

### 3?? 环境稳定性检查 ?

**目的**: 确保不是在气压剧烈波动时标定

```c
检查最近10次采样（10分钟）:
  压力方差 < 0.5 hPa?
  温度方差 < 0.3 °C?

计算方式:
variance = Σ(x - mean)? / n

if (pressure_variance < 0.5 && temp_variance < 0.3) {
    通过 ?  // 环境稳定
} else {
    不通过 ?  // 可能在下雨、刮风等
}
```

**意义**: 
- 防止在天气变化时标定
- 确保是平稳状态下的大气压

---

### 4?? 无水浸状态检查 ?

**目的**: 确保真的没有水！

```c
检查当前是否处于水浸模式:
if (shared_params_get_device_water() == 0) {
    通过 ?  // 没有水浸
} else {
    不通过 ?  // 有水，绝对不能标定！
}
```

**意义**: 
- 最关键的检查！
- 有水时标定 = 把有水当成无水 = 严重错误
- 防止在实际水浸时错误标定

---

### 5?? 基准合理性检查 ?

**目的**: 避免标定到异常值

```c
读取当前压力作为候选新基准:
new_baseline = current_pressure

检查1: 绝对范围
if (900 hPa < new_baseline < 1100 hPa) {
    合理 ?
} else {
    不合理 ?  // 传感器可能故障
}

检查2: 变化幅度
change = abs(new_baseline - old_baseline)
if (change <= 15 hPa) {
    合理 ?  // 正常的气压变化范围
} else {
    不合理 ?  // 变化太大，可能有问题
}
```

**意义**: 
- 防止传感器故障时标定
- 防止异常数据污染基准

## ? 标定的具体过程

### 满足所有条件后的执行流程

```c
1. 记录旧基准
   old_baseline = wf5803f_get_baseline_pressure();

2. 执行标定
   wf5803f_set_baseline_pressure(0.0f);  // 0表示使用当前读数

3. WF5803F内部操作
   current_pressure = 从传感器读取();
   baseline_pressure = current_pressure;  // 设为新基准
   
4. 获取新基准
   new_baseline = wf5803f_get_baseline_pressure();

5. 验证标定
   if (900 < new_baseline < 1100) {
       标定成功 ?
       更新 last_calibration_time
   } else {
       标定失败 ?
       恢复旧基准
   }
```

## ? 标定的假设和前提

### 核心假设

**标定时假设**:
```
当前时刻 = 无水状态
当前气压 = 真实大气压力
水深 = 0 cm
```

**标定后的水深计算**:
```
water_depth = (current_pressure - baseline_pressure) × 1.0 cm/hPa
```

### 为什么这个假设合理？

**通过5层检查保证**:
1. ? 时间合理（6小时-7天）
2. ? 环境稳定（方差小）
3. ? 无水浸（shared_params确认）
4. ? 时段合适（全天候）
5. ? 数值合理（900-1100 hPa）

**结论**: 5个条件同时满足时，"当前无水"的假设几乎一定正确

## ? 总结

### 标定依据

**核心依据**: 当前气压读数

**前提假设**: 当前时刻无水（水深=0）

**保障机制**: 5层严格检查确保假设正确

### 标定的本质

```
标定 = 重新定义"0水深"
     = 更新无水状态下的气压参考值
     = 适应大气压力的缓慢变化
```

### 安全性

**多重保护**:
- 时间限制（6小时-7天）
- 环境稳定检查（防止天气变化）
- 水浸状态检查（防止有水时标定）
- 数值合理性检查（防止异常）

**结论**: 智能标定系统的依据充分、逻辑严谨、安全可靠！?
