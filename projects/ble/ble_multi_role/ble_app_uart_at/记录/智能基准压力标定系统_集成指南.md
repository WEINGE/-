# 智能基准压力标定系统 - 集成指南

## ? 问题背景

### 核心挑战
1. **大气压自然波动**：天气变化导致大气压波动 ±10hPa，影响传感器精度
2. **水浸误判风险**：如果在水浸状态下进行基准标定，会将水浸压力误认为正常值
3. **标定时机选择**：需要智能判断最佳标定时间，避免干扰正常监测

### 解决方案概述
**智能基准压力自动标定系统** - 通过多层安全检查机制，在保证安全的前提下自动进行基准压力校准。

## ? 系统架构

### 核心模块
```
smart_baseline_calibration.h/c
├── 时间窗口控制 (凌晨2-5点自动标定)
├── 环境稳定性检测 (压力/温度波动分析)
├── 水浸状态识别 (多重验证防止误标定)
├── 基准值合理性验证 (防止异常值)
└── 统计和诊断功能 (监控标定成功率)
```

### 工作流程
```
1. 持续采样 → 累积10次稳定数据
2. 定时检查 → 每小时检查一次是否需要标定
3. 条件判断 → 时间窗口 + 环境稳定 + 无水浸
4. 执行标定 → 调用WF5803F驱动完成标定
5. 验证结果 → 检查新基准合理性
6. 异常回滚 → 如有问题立即恢复旧值
```

static app_timer_id_t m_calibration_check_timer;

#define CALIBRATION_CHECK_INTERVAL_MS  3600000  // 1小时检查一次

// 定时器回调函数
static void calibration_check_timer_handler(void *p_context)
{
    // 获取当前RTC时间
    uint8_t current_hour = 0;
    extern bool bm8563_get_hour(uint8_t *hour);  // 从RTC获取小时
    if (bm8563_get_hour(&current_hour)) {
        
        // 执行智能标定调度
        uint32_t current_time_ms = app_timer_get_elapsed_time_ms();
        bool calibrated = smart_calibration_schedule(current_time_ms, current_hour);
        
        if (calibrated) {
            APP_LOG_INFO("%s Automatic baseline calibration completed", DEBUG_TAG);
            
            // 可选：通过BLE通知用户
            // send_calibration_notification();
        }
    }
}

// 在 ble_4g_protocol_init() 中创建定时器
void ble_4g_protocol_init(void)
{
    // ... 其他初始化 ...
    
    // 创建标定检查定时器
    sdk_err_t err_code;
    err_code = app_timer_create(&m_calibration_check_timer,
                                ATIMER_REPEAT,
                                calibration_check_timer_handler);
    if (err_code != SDK_SUCCESS) {
        APP_LOG_ERROR("%s Failed to create calibration check timer", DEBUG_TAG);
    }
    
    // 启动定时器
    err_code = app_timer_start(m_calibration_check_timer, 
                              CALIBRATION_CHECK_INTERVAL_MS, 
                              NULL);
    if (err_code == SDK_SUCCESS) {
        APP_LOG_INFO("%s Calibration check timer started (1 hour interval)", DEBUG_TAG);
    }
}

## ?? 配置参数调优

### 关键参数说明

#### 1. 标定时间策略
```c
#define CALIBRATION_MIN_INTERVAL_MS       86400000   // 最小24小时
#define CALIBRATION_MAX_INTERVAL_MS       604800000  // 最多7天
```
**建议**：
- 矿山环境：7天强制标定
- 城市环境：3天强制标定
- 稳定环境：可延长到14天

#### 2. 环境稳定性阈值
```c
#define STABILITY_PRESSURE_VARIANCE_HPA   0.5f       // 压力波动
#define STABILITY_TEMP_VARIANCE_C         0.3f       // 温度波动
```
**调整建议**：
- 压力波动大的环境：增大到 1.0f
- 温度波动大的环境：增大到 0.5f

#### 3. 水浸检测阈值
```c
#define FLOOD_DETECTION_DELTA_HPA         8.0f       // 8hPa ≈ 8cm水深
#define FLOOD_CONTINUOUS_COUNT            3          // 连续3次确认
```
**调整建议**：
- 提高灵敏度：降低到 5.0f（5cm水深）
- 降低误报：增加连续次数到 5

#### 4. 标定时间窗口
```c
#define CALIBRATION_WINDOW_START_HOUR     2          // 凌晨2点
#define CALIBRATION_WINDOW_END_HOUR       5          // 凌晨5点
```
**调整建议**：
- 24小时运行场景：禁用时间窗口
  ```c
  smart_calibration_set_time_window_enable(false);
  ```

## ?? 注意事项

1. **首次部署**：建议先禁用自动标定，手动观察1-2周后再启用
2. **时间同步**：确保RTC时间准确，否则时间窗口功能无效
3. **看门狗**：标定过程需要访问传感器，确保看门狗超时时间足够
4. **Flash写入**：如果基准值需要持久化，记得保存到Flash
5. **电源管理**：标定期间需要传感器供电，注意功耗

## ? 常见问题

### Q1: 标定从不执行？
**A**: 检查以下几点：
1. 时间窗口是否正确（默认凌晨2-5点）
2. 环境是否足够稳定（查看日志的variance值）
3. 是否距离上次标定太近（至少24小时）

### Q2: 频繁误报水浸？
**A**: 调整水浸检测阈值：
```c
#define FLOOD_DETECTION_DELTA_HPA  12.0f  // 提高阈值
#define FLOOD_CONTINUOUS_COUNT     5      // 增加确认次数
```

### Q3: 如何禁用时间窗口限制？
**A**: 在初始化后添加：
```c
smart_calibration_set_time_window_enable(false);
```

### Q4: 如何立即强制标定？
**A**: 通过BLE发送命令或调用：
```c
smart_calibration_force_trigger(false);  // 不跳过安全检查
```
