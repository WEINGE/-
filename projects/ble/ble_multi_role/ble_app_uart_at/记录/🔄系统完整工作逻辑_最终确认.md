### 执行流程

```
每1分钟执行:
  ↓
1. 开启传感器电源
   delay 500ms
   ↓
2. 初始化传感器
   sensor_data_init()
   ↓
3. 读取传感器数据
   sensor_data_read(&sensor_reading)
   ├─ 读取 WF5803F (I2C)
   │  └─ pressure_hpa, temperature_c
   └─ 读取水位传感器 (UART)
       └─ level_grade
   ↓
4. 水浸检测（简单阈值）
   water_depth_cm = shared_params_get_water_depth_threshold()
   pressure_threshold = wf5803f_water_depth_to_pressure(water_depth_cm)
   
   if (wf5803f_detect_flood(pressure_threshold)) {
       进入水浸模式
       shared_params_set_device_water(1)
   }
   ↓
5. 缓存数据（供后续上报）
   ↓
6. 关闭传感器电源
```

**关键点**: 
- ? 每分钟读取一次传感器
- ? 使用简单阈值检测水浸

## ? 智能标定内部流程

### smart_calibration_schedule() 详细流程

```
输入: 
  - current_time_ms: 累积时间戳
  - current_rtc_hour: 当前小时
  
执行:
  ↓
1. 检查调用间隔（防抖动）
   if (current_time_ms - last_check_time < 3600000) {
       return false;  // 1小时内已检查过
   }
   ↓
2. 检查时间间隔
   time_since_last = current_time_ms - last_calibration_time
   
   if (time_since_last < 21600000) {  // 6小时
       return false;  // 距上次标定不足6小时
   }
   
   if (time_since_last > 604800000) {  // 7天
       force_calibrate = true;  // 超过7天，强制标定
   }
   ↓
3. 检查时间窗口
   if (current_rtc_hour < 0 || current_rtc_hour > 23) {
       return false;  // 不在0-23点（实际总是true）
   }
   ↓
4. 检查环境稳定性 ??
   【这里可能有问题】
   
   如果有历史数据:
     计算最近10次采样的方差
     if (压力方差 > 5.0 || 温度方差 > 999.0) {
         return false;  // 环境不稳定
     }
   
   如果没有历史数据:
     可能跳过检查或总是通过
   ↓
5. 检查水浸状态
   if (shared_params_get_device_water() != 0) {
       return false;  // 当前有水浸，不能标定
   }
   ↓
6. 执行标定
   wf5803f_set_baseline_pressure(0.0f);  // 0表示使用当前读数
   new_baseline = wf5803f_get_baseline_pressure();
   ↓
7. 验证标定结果
   if (900 < new_baseline < 1100 && 变化量 <= 15) {
       last_calibration_time = current_time_ms;
       return true;  // 标定成功
   } else {
       恢复旧基准
       return false;  // 标定失败
   }
```
