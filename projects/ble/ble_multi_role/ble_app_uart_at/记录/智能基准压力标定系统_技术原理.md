## ? 决策判断逻辑

### 1. 环境稳定性判断

```
输入: 最近10次采样 {P1, P2, ..., P10}, {T1, T2, ..., T10}

步骤1: 计算压力方差
     P_mean = (P1 + P2 + ... + P10) / 10
     P_var = Σ(Pi - P_mean)? / 10

步骤2: 计算温度方差
     T_mean = (T1 + T2 + ... + T10) / 10
     T_var = Σ(Ti - T_mean)? / 10

步骤3: 判断稳定性
     if (P_var < 0.5 hPa? AND T_var < 0.3°C?):
         环境稳定 ?
     else:
         环境不稳定 ?
```

**实例分析**：
```
情况1 (稳定环境):
压力: [1013.2, 1013.3, 1013.1, 1013.2, 1013.3, 1013.2, 1013.1, 1013.2, 1013.3, 1013.2] hPa
P_var = 0.0061 hPa? < 0.5 ?
温度: [24.9, 25.0, 24.9, 25.0, 25.0, 24.9, 25.0, 25.0, 24.9, 25.0] °C
T_var = 0.0025 °C? < 0.3 ?
结论: 环境稳定，可以标定 ?

情况2 (不稳定环境):
压力: [1013.0, 1014.5, 1012.8, 1015.2, 1011.9, ...] hPa
P_var = 1.8 hPa? > 0.5 ?
结论: 环境不稳定，不能标定 ?
```

### 2. 水浸状态检测

```
多重验证策略:

第一层: 压力差值检测
    Δ P = 当前压力 - 基准压力
    if (ΔP > 8.0 hPa):
        怀疑水浸，进入第二层验证

第二层: 连续性确认
    连续检测计数器 +1
    if (连续检测计数 ≥ 3):
        确认水浸 ??
    else:
        继续观察

第三层: 安全缓冲
    if (ΔP < 2.0 hPa):
        安全计数器 +1
        if (安全计数 ≥ 3):
            重置水浸计数器
            确认安全 ?
```

**水深与压力对应关系**：
```
水深(cm)   压力变化(hPa)   状态
  0cm        0 hPa         正常 ?
  5cm        5 hPa         注意
  8cm        8 hPa         怀疑水浸 ??
 10cm       10 hPa         确认水浸 ????
 15cm       15 hPa         严重水浸 ?
```

### 3. 基准值合理性验证

```
输入: 新基准值 baseline_new

检查1: 绝对值范围
    if (900 ≤ baseline_new ≤ 1100 hPa):
        通过 ?
    else:
        拒绝 ? (超出正常大气压范围)

检查2: 变化幅度
    if (旧基准存在):
        Δ = |baseline_new - baseline_old|
        if (Δ ≤ 15 hPa):
            通过 ? (正常气压波动)
        else:
            拒绝 ? (变化过大，可能异常)
```

**实例**：
```
场景1: 正常气压变化
旧基准: 1013.0 hPa
新基准: 1018.5 hPa
变化: 5.5 hPa ≤ 15 hPa ?
结论: 合理，可能是天气变化

场景2: 异常变化
旧基准: 1013.0 hPa
新基准: 1030.0 hPa  
变化: 17.0 hPa > 15 hPa ?

```

1. 环境稳定
   - 温度变化最小

## ?? 安全机制

### 多层防护体系

```
Layer 1: 时间间隔保护
    └─ 防止频繁标定导致系统不稳定
       最小间隔: 24小时
       最大间隔: 7天(强制标定)

Layer 2: 环境稳定性保护
    └─ 防止在不稳定环境中标定
       压力方差阈值: 0.5 hPa?
       温度方差阈值: 0.3°C?
       最少采样数: 8/10

Layer 3: 水浸状态保护
    └─ 防止在水浸状态下误标定
       压力阈值: +8 hPa
       连续确认: 3次
       安全缓冲: 2 hPa

Layer 4: 基准值验证保护
    └─ 防止异常值破坏系统
       绝对范围: 900-1100 hPa
       变化限制: ±15 hPa
       异常回滚机制

Layer 5: 时间窗口保护
    └─ 选择最佳标定时机
       凌晨2-5点
       可配置开关
```

### 故障恢复机制

```
标定失败 → 自动回滚
    │
    ├─ 保存标定前基准值
    ├─ 验证新基准是否合理
    ├─ 如不合理，立即恢复旧值
    └─ 记录失败原因，等待下次重试

连续失败 → 告警上报
    │
    ├─ 连续3次失败 → 发送警告
    ├─ 连续7次失败 → 发送告警
    └─ 建议人工检查
```
