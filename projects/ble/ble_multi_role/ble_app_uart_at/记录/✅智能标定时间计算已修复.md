### 修复后 ?
```c
static void calibration_check_timer_handler(void *p_context)
{
    static uint32_t calibration_time_ms = 0;  // ? 静态计数器
    
    rtc_time_t rtc_time;
    
    // RTC失败则跳过本次检查
    if (!bm8563_read_time(&rtc_time)) {
        APP_LOG_WARNING("RTC read failed, skip this check");
        return;  // ? 添加保护
    }
    
    // 每次调用增加1小时
    calibration_time_ms += 3600000;  // ? 累加时间
    
    bool calibration_attempted = smart_calibration_schedule(
        calibration_time_ms,  // ? 正确的累积时间戳
        rtc_time.hour         // ? RTC小时
    );
    
    if (calibration_attempted) {
        float new_baseline = wf5803f_get_baseline_pressure();
        APP_LOG_INFO("Baseline updated: %.2f hPa", new_baseline);
    }
}
```

**改进**:
1. ? 使用静态计数器（与原有系统一致）
2. ? 正确累加时间（每小时+3600000ms）
3. ? 正确传递时间戳
4. ? RTC失败时跳过检查

## ? 工作原理

### 时间累加示例

```
系统启动:
  T=0:     calibration_time_ms = 0

第1小时:
  T=1小时:  calibration_time_ms = 0 + 3600000 = 3600000
  时间间隔: 3600000 - 0 = 1小时 < 6小时 → 不标定

第6小时:
  T=6小时:  calibration_time_ms = 21600000
  时间间隔: 21600000 - 0 = 6小时 = 6小时 → 执行标定！
  更新: last_calibration_time = 21600000

第7小时:
  T=7小时:  calibration_time_ms = 25200000
  时间间隔: 25200000 - 21600000 = 1小时 < 6小时 → 不标定

第12小时:
  T=12小时: calibration_time_ms = 43200000
  时间间隔: 43200000 - 21600000 = 6小时 → 执行标定！
```
