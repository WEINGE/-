# ?? 重要发现：漂移阈值确实会影响标定！

## ? 直接回答您的问题

**是的！如果不超过漂移阈值，在某些情况下可能不会标定！**

## ? 实际代码逻辑

### smart_calibration_is_needed() 函数

```c
bool smart_calibration_is_needed(uint32_t current_time_ms)
{
    uint32_t time_since_last = current_time_ms - last_calibration_time;
    
    // 1. 从未标定过 → 需要标定
    if (last_calibration_time == 0) {
        return true;  // ? 一定会标定
    }
    
    // 2. 距上次标定太近（< 6小时）→ 不标定
    if (time_since_last < 6小时) {
        return false;  // ? 不标定
    }
    
    // 3. 超过最大间隔（> 7天）→ 强制标定
    if (time_since_last > 7天) {
        return true;  // ? 一定会标定
    }
    
    // 4. 检查基准漂移 ← 关键！
    if (缓冲区有数据) {
        float recent_avg = 计算最近10次平均压力();
        float drift = abs(recent_avg - baseline);
        
        if (drift > 5.0 hPa) {  // ← 漂移阈值检查！
            return true;  // ? 漂移超过5hPa，需要标定
        }
    }
    
    // 5. 默认不需要标定
    return false;  // ? 不标定
}
```

## ? 关键发现

### 标定触发条件（3个）

**满足任一条件即可标定**:

1. **从未标定过** ?
   ```
   第一次运行 → 一定会标定
   ```

2. **超过最大间隔（7天）** ?
   ```
   距上次标定 > 7天 → 强制标定
   ```

3. **基准漂移超过阈值（5 hPa）** ?
   ```
   当前压力平均值 - baseline > 5 hPa → 需要标定
   ```

### ?? 问题场景

**如果漂移不超过5 hPa**:

```
场景:
  上次标定: 3天前
  当前漂移: 3 hPa（< 5 hPa阈值）
  
判断流程:
  1. 从未标定？ 否
  2. 距上次 < 6小时？ 否（3天）
  3. 距上次 > 7天？ 否（3天）
  4. 漂移 > 5 hPa？ 否（3 hPa < 5 hPa）
  5. return false
  
结果:
  ? 不会标定！
  ? 即使时间已经过了3天
  ? 要等到漂移超过5 hPa 或 满7天
```

## ?? 潜在问题

### 问题1: 小漂移长期累积

```
如果气压每天缓慢上升1 hPa:
  T=0:    baseline=1011, drift=0
  T=1天:  pressure=1012, drift=1 hPa → 不标定
  T=2天:  pressure=1013, drift=2 hPa → 不标定
  T=3天:  pressure=1014, drift=3 hPa → 不标定
  T=4天:  pressure=1015, drift=4 hPa → 不标定
  T=5天:  pressure=1016, drift=5 hPa → 标定 ?
  
问题: 4天内都有3-4cm误差
```

### 问题2: 阈值太大导致精度不足

```
如果您的水浸检测阈值是3cm:
  但基准漂移5cm才标定
  → 可能在4cm漂移时误报水浸
```

## ? 解决方案

### 方案A: 降低漂移阈值（推荐）

**如果需要更高精度**:
```c
#define BASELINE_DRIFT_THRESHOLD_HPA   2.0f  // 改为2cm

效果:
  - 2 hPa漂移就标定
  - 更频繁标定
  - 误差更小
```

### 方案B: 依赖时间间隔

**保持当前配置**，依赖7天强制标定:
```c
#define BASELINE_DRIFT_THRESHOLD_HPA   5.0f  // 保持

效果:
  - 最多7天一定标定
  - 可能有5cm误差
  - 适合低精度应用
```

### 方案C: 禁用漂移检查（不推荐）

**设为极大值**:
```c
#define BASELINE_DRIFT_THRESHOLD_HPA   999.0f

效果:
  - 只依赖7天强制标定
  - 可能长期有误差
  - 不推荐
```
