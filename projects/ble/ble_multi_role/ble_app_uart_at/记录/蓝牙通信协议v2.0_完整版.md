3.5 监测数据上报
Header
序号	字段名	类型	注释
1	code	int	命令代码105
Body
序号	字段名	类型	注释
1	sensor_pressure	string	气压和水深，格式："气压hPa,水深cm"
2	sensor_TEMP	int	温度值，单位℃
3	sensor_battery	string	电池电压与电池电量百分比，格式："电压V,电量%"
4	water_level	string	水位传感器数据，格式："档位,水位高度cm,温度℃"
5	water_level_cap	string	水位传感器电容值，格式："C0,C1,C2,C3,C4,C5,C6"，单位pF
Result
序号	字段名	类型	注释
1	result	int	0:自动上报信息，1:查询指令回文
报文方向：设备->APP
报文格式：
{
"header":{
    "code":105,//命令代码
},
"body":{
"sensor_pressure":"1013.25,50.0",
"sensor_TEMP":25,
"sensor_battery":"3.850,85",
"water_level":"3,5.4,21.5",
"water_level_cap":"12.35,15.28,18.92,22.15,25.67,28.34,30.12"
},
"result":1
}

字段说明：
1. sensor_pressure: "气压hPa,水深cm"
   - 气压：浮点数，2位小数，单位hPa（百帕）
   - 水深：浮点数，1位小数，单位cm（厘米）
   - 示例："1013.25,50.0" 表示气压1013.25hPa，水深50.0cm

2. water_level: "档位,水位高度cm,温度℃"
   - 档位：整数，范围0~6
   - 水位高度：浮点数，1位小数，单位cm
   - 温度：浮点数，1位小数，单位℃
   - 示例："3,5.4,21.5" 表示档位3，水位高度5.4cm，温度21.5℃

3. water_level_cap: "C0,C1,C2,C3,C4,C5,C6"
   - 7个通道电容值，浮点数，2位小数，单位pF（皮法）
   - 示例："12.35,15.28,18.92,22.15,25.67,28.34,30.12"

注意事项：
1. 校准前必须确保水位传感器周围无液体（空载状态）
2. 校准过程约需3-5秒，期间不应读取数据
3. 校准成功后立即生效，数据存储在传感器内部
4. 建议在首次安装或更换容器后执行校准

附录C：数据类型说明

1. 气压数据 (sensor_pressure)
   - 格式："气压hPa,水深cm"
   - 气压范围：300.0 ~ 1100.0 hPa
   - 水深范围：0.0 ~ 500.0 cm
   - 水深计算：基于压力变化，1cm水深≈0.98hPa

2. 水位传感器基础数据 (water_level)
   - 格式："档位,水位高度cm,温度℃"
   - 档位范围：0 ~ 6
   - 水位高度：档位 × 1.8 cm
   - 温度范围：-40.0 ~ 85.0 ℃

3. 水位传感器电容数据 (water_level_cap)
   - 格式："C0,C1,C2,C3,C4,C5,C6"
   - 单位：pF（皮法）
   - 范围：0.00 ~ 99.99 pF
   - 用途：用于精确诊断传感器工作状态

附录E：设备ID说明

device_ID类型及优先级：
1. 优先使用IMEI（4G模块ID）
2. 如IMEI不可用，使用MAC地址（蓝牙MAC）
3. 每个设备ID唯一，用于平台设备识别

ID格式示例：
- IMEI: "860123456789012" (15位数字)
- MAC: "E8DB849C5E3A" (12位十六进制，大写)
