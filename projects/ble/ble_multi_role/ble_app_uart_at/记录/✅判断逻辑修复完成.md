## ? 修复后的逻辑

### 新代码
```c
if (can_analyze && 增强型确认水浸) {
    // 增强型判断是水浸
    报警;
} else if (!can_analyze) {
    // 增强型不可用（样本不足<10分钟）
    // 才使用阈值检测作为备份
    if (水深 >= 阈值) {
        报警;
    }
}
// 否则：增强型可用但判断不是水浸
// → 不报警（即使超过阈值）
```

### 逻辑说明
```
判断流程:

1. 增强型可用 && 确认水浸 → 报警
2. 增强型可用 && 不是水浸 → 不报警（关键！）
3. 增强型不可用 && 超过阈值 → 报警（备份）
4. 增强型不可用 && 未超阈值 → 不报警
```
