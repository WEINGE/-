## ?? 多重安全保护机制

### 标定条件（5层检查，全部满足才执行）

```
第1层: 时间间隔
  ┌─ 最小间隔: ≥24小时
  └─ 最大间隔: ≤7天（触发强制检查）

第2层: 时间窗口
  ┌─ 正常: 凌晨2-5点
  └─ 强制: 任何时间（7天后）

第3层: 环境稳定性（关键！）
  ┌─ 压力方差: <0.5 hPa?
  └─ 温度方差: <0.3°C?
  → 下雨时方差会超标，不会标定 ?

第4层: 水浸状态
  ┌─ 增强型检测: 未检测到水浸
  └─ 阈值检测: 未超过阈值

第5层: 基准合理性
  ┌─ 绝对范围: 900-1100 hPa
  ┌─ 变化幅度: ≤15 hPa
  └─ 异常回滚: 不合理时恢复旧值
```

```

  正常模式: 需要满足时间窗口

  ? 环境稳定

```

  下雨 → 压力剧烈波动

       → 方差超标
       → 环境不稳定检查失败
       → 不执行标定 ?

  2. 通知增强型检测器
  3. 两个系统同步使用新基准
  
确保:
  所有模块使用一致的基准
