## ? 关键技术特性

### 1. 多因子评分系统
```
4个维度:
  - 变化速率 (0-1分)
  - 变化幅度 (0-1分)
  - 温度关联 (0-1分)
  - 压力稳定性 (0-1分)

总分 ≥ 2.5/4.0 → 确认水浸
总分 < 2.5/4.0 → 大气压变化
```

### 2. 连续确认机制
```
需要连续3次检测到水浸才确认
避免瞬时干扰（电梯、震动等）
```

### 3. 五层标定检查
```
1. 时间间隔 (24小时-7天)
2. 时间窗口 (凌晨2-5点)
3. 环境稳定性 (方差检查)
4. 无水浸状态
5. 基准合理性
```

### 4. 上报值智能修正
```
if (增强型确认水浸) {
    上报: 实际水深值
} else {
    上报: 0 (防止平台误报)
}
```
