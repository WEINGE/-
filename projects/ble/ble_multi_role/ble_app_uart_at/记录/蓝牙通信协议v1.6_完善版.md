### 3.5 监测数据上报

**Header**

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | code | int | 命令代码105 |

**Body**

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | sensor_pressure | string | 气压和水深数据，格式："气压hPa,水深cm" |
| 2 | sensor_TEMP | int | 温度值，单位℃ |
| 3 | sensor_battery | string | 电池电压与电池电量百分比，格式："电压V,百分比%" |
| 4 | water_level | string | （可选）电子水尺数据，格式："档位,水位高度cm,温度℃"（MER-MCP1081传感器） |
| 5 | water_level_cap | string | （可选）电容值数据，格式："C0,C1,C2,C3,C4,C5,C6"（单位pF） |

**Result**

| 序号 | 字段名 | 类型 | 注释 |
|------|--------|------|------|
| 1 | result | int | 0:自动上报信息，1:查询指令回文 |

**报文方向**：设备->APP

**报文格式**：
```json
{
  "header": {
    "code": 105
  },
  "body": {
    "sensor_pressure": "1013.25,0.0",
    "sensor_TEMP": 25,
    "sensor_battery": "3.600,100",
    "water_level": "3,5.4,24.5",
    "water_level_cap": "12.34,23.45,34.56,45.67,56.78,67.89,78.90"
  },
  "result": 1
}
```

**说明**：
- `sensor_pressure`：气压（hPa）和水深（cm）组合，用于水位监测
- `water_level`：MER-MCP1081-22-150电子水尺的档位、高度和温度
- `water_level_cap`：7个电容值（C0-C6），单位pF

## 4. 传感器说明

本系统使用以下传感器：

1. **WF5803F气压传感器**：用于水位监测，通过气压变化计算水深
   - 输出数据：气压（hPa）、温度（℃）、海拔（m）
   - 水深计算：1cm水深≈0.98hPa压力变化

2. **MER-MCP1081-22-150电子水尺**：用于辅助水位检测
  - 输出数据：档位（0-6）、水位高度（cm）、温度（℃）、7个电容值（pF）
   - 每档约1.8cm水位高度

3. **电池电压监测**：实时监测电池状态
   - 输出数据：电压（V）、电量百分比（%）

## 5. 注意事项

1. **设备ID**：优先使用4G模块的IMEI作为设备ID，如无法获取IMEI则使用MAC地址
2. **时间格式**：时间戳使用12位数字格式"YYYYMMDDHHmm"
3. **坐标格式**：经纬度坐标格式为"经度,纬度"，例如"113.253342,25.684351"
4. **信号强度**：4G信号值范围0-31，越大越好，一般大于17能够正常稳定工作
5. **防盗判断**：定位坐标与安装坐标差距在半径20m内视作正常
6. **水深阈值**：默认5cm，可通过Code 108设置
7. **浮点精度**：浮点数值会按两位小数四舍五入，避免显示异常
