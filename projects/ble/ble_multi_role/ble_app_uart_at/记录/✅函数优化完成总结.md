### ? 时间戳获取优化

#### 修改前（使用RTC计数器）
```c
// 问题：不精确，非标准做法
(uint32_t)(sdk_rtc_counter_get() / 32)
```

#### 修改后（使用静态计数器）?
```c
// 优化：与原有代码模式一致（参考water_level_sensor.c）

```

## ? 优化效果

### 1. 代码更清晰
```
修改前: (uint32_t)(sdk_rtc_counter_get() / 32)  ? 难以理解
修改后: g_sample_timestamp_counter++            ? 清晰明了
```

### 2. 与原有代码一致
```
原有模式（water_level_sensor.c 第509行）:
  static uint32_t counter = 0;
  p_data->timestamp = counter++;

我们的模式:
  static uint32_t g_sample_timestamp_counter = 0;
  g_sample_timestamp_counter++

? 完全一致！
```

### 3. 更可靠
```
RTC计数器方案:
  - 可能溢出
  - 除法不精确
  - 未经验证

静态计数器方案:
  - 简单递增
  - 完全精确
  - 原有代码已验证
```

### 4. 满足需求
```
增强型检测只需要:
  ? 相对时间间隔
  ? 不需要绝对时间

静态计数器:
  ? 提供精确的相对时间
  ? 每分钟+1，完美匹配采样频率
  ? 10次采样 = 10分钟，用于计算速率
```
