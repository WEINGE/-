## ***\*3\*******\*.\*******\*2\**** ***\*状态信息上报\****

Header

| 序号 | 字段名    | 类型   | 注释        |
| ---- | --------- | ------ | ----------- |
| 1    | code      | int    | 命令代码103 |
| 2    | device_ID | string | 设备ID      |

Body

| 序号 | 字段名                       | 类型   | 注释                                                       |
| ---- | ---------------------------- | ------ | ---------------------------------------------------------- |
| 1    | device_water                 | int    | 水浸状态（1：水浸，0：未水浸）                             |
| 2    | sensor_status                | int    | 激光传感器状态（0：正常，1：异常）                         |

| 5    | device_GPS_status            | int    | GPS信号状态（0：正常，1：异常）能获取到定位坐标为正常      |
| 6    | device_location              | string | 设备定位信息（经纬度）                                     |
| 7    | device_installation_location | string | 设备安装位置信息（经纬度）                                 |

## ***\*3\*******\*.\*******\*3\**** ***\*当前设置参数上报\****

Header

| 序号 | 字段名    | 类型   | 注释        |
| ---- | --------- | ------ | ----------- |
| 1    | code      | int    | 命令代码104 |
| 2    | device_ID | string | 设备ID      |

Body

| 序号 | 字段名              | 类型  | 注释                                                         |
| ---- | ------------------- | ----- | ------------------------------------------------------------ |
| 1    | device_collect_time | int   | 传感器采集间隔，单位分钟                                     |
| 2    | device_updata_time  | int   | 数据上报间隔，单位分钟                                       |
| 3    | methane_threshold   | float | 甲烷报警阈值浓度，单位%vol，高于此值报警                     |
| 4    | TEMPH_threshold     | int   | 高温报警阈值，单位℃，高于此值报警                            |
| 5    | TEMPL_threshold     | int   | 低温报警阈值，单位℃，低于此值报警                            |
| 6    | water_threshold     | int   | 水浸报警阈值，数值根据传感器类型变动，如果采用开关试水浸传感器可忽略此项 |

报文方向：设备->平台

报文格式：

{“header”:{  “code”:104,//命令代码  “device_ID”:”……”},“body”:{“device_collect_time”:1440,“device_update_time”:1440,“methane_threshold”:5,“TEMPH_threshold”:50,“TEMPL_threshold”:-20,“water_threshold”:……,}}

# ***\*4\*******\*.\**** ***\*服务器参数及上传逻辑\****

4G上传使用MQTT协议

地址：mqtt://emqx.changyg.top

端口：23622

用户名：ThingsBoard

密码：ctkjThingsBoard

MQTT客户端ID：使用设备ID

设备上报主题：/methane_sensor/test/report

指令下发主题：/methane_sensor/test/command

 

数据上传逻辑：设备在达到设定时间间隔后唤醒启动，上传数据后发送查询设置变更命令，若平台有设置变更则会使用设置命令对设备参数进行设置，设备ID”FFFFFFFFFFFF”（如果用MAC地址作为设备ID）为广播地址，平台在发送设置命令时使用此ID将视为对所有在线设备的设置动作。设备在接收最后一条设置命令后10S内无其他设置命令则再次休眠。
