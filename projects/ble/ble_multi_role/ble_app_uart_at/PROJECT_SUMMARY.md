# 水位/水浸监测终端项目总结

## 项目概述

本项目是基于 **汇顶科技(GOODIX) GR5515** 芯片的水位/水浸监测物联网终端设备固件，实现了通过 **BLE(蓝牙低功耗)** 和 **4G(LTE)** 双通道进行数据采集、报警和远程上报的功能。

### 核心功能

| 功能模块 | 描述 |
|---------|------|
| **水浸检测** | 基于WF5803F气压传感器检测水深变化，自动触发报警模式 |
| **水位检测** | 集成MER-MCP1081-22-150电子水尺，7档位电容式液位检测 |
| **双通道通信** | BLE本地配置 + 4G远程上报，支持MQTT协议 |
| **智能电源管理** | 传感器按需上电，DTU定时唤醒，低功耗设计 |
| **RTC时间同步** | 通过4G网络获取时间同步到BM8563 RTC芯片 |

### 核心模块说明

#### 1. 共享参数管理 (`shared_params`)

蓝牙和4G协议共享的设备参数，支持Flash持久化存储：

```c
typedef struct {
    uint16_t device_collect_time;       // 采集间隔（分钟）
    uint16_t device_updata_time;        // 上报间隔（分钟）
    float    water_depth_threshold_cm;  // 水深报警阈值(cm)
    int16_t  temp_high_threshold;       // 高温报警阈值(℃)
    int16_t  temp_low_threshold;        // 低温报警阈值(℃)
    // ... 服务器配置、设备信息等
} shared_device_params_t;
```

#### 2. 4G协议命令 (`ble_4g_protocol`)

| 命令码 | 功能 | 方向 |
|--------|------|------|
| 102 | 设备信息上报 | 设备→服务器 |
| 103 | 状态信息上报 | 设备→服务器 |
| 104 | 参数设置上报 | 设备→服务器 |
| 105 | 监测数据上报 | 设备→服务器 |
| 106 | 采集周期设置 | 服务器→设备 |
| 107 | 上报周期设置 | 服务器→设备 |
| 108 | 阈值设置 | 服务器→设备 |
| 110 | 水浸阈值设置 | 服务器→设备 |
| 120 | 查询设置变更 | 服务器→设备 |

#### 3. 水浸报警模式

当检测到水浸时，系统自动切换到紧急模式：

| 模式 | 采集间隔 | 上报间隔 |
|------|----------|----------|
| 正常模式 | 用户设置(默认60分钟) | 用户设置(默认1440分钟) |
| 水浸模式 | **3分钟** | **3分钟** |

## 数据采集与上报流程

### 采集定时器触发流程

```
sensor_collect_timer_handler()
  │
  ├── 1. 电源管理读取传感器数据
  │      ├── 上电传感器(S_EN, P_M_EN)
  │      ├── 读取WF5803F气压/温度
  │      ├── 读取MCP1081水位档位
  │      ├── 读取电池电压
  │      └── 断电传感器
  │
  ├── 2. 获取RTC时间戳
  │
  ├── 3. 水浸检测与模式切换
  │      ├── 计算水深 = (当前气压 - 基准气压) / 0.98
  │      ├── 水深 > 阈值 → 进入水浸模式(3分钟间隔)
  │      └── 水深 < 阈值 → 退出水浸模式(恢复正常间隔)
  │
  ├── 4. 更新状态信息(103)
  │
  └── 5. 数据存入累积数组(最多24条)
```

### 上报定时器触发流程

```
data_report_timer_handler()
  │
  ├── 1. 上电DTU(P_M_EN, 4G_EN)
  ├── 2. 打开UART1
  ├── 3. 等待DTU就绪(10秒)
  │
  ├── 4. 发送JSON数据包
  │      ├── 102 设备信息
  │      ├── 103 状态信息
  │      ├── 104 参数设置
  │      └── 105 监测数据(批量)
  │
  ├── 5. 等待发送完成(5秒)
  ├── 6. 关闭UART1
  └── 7. 断电DTU
```

## 关键技术特性

### 1. 低功耗设计

- **传感器按需上电**：采集时才上电，采集完立即断电
- **DTU定时唤醒**：上报时才上电4G模块
- **BLE广播间隔优化**：无连接时降低广播频率
- **芯片睡眠模式**：主循环中调用 `pwr_mgmt_schedule()`

### 2. 参数持久化

- 所有配置参数存储在Flash中
- 参数版本号机制防止结构体变更导致的兼容问题
- 校验和验证数据完整性

### 3. 看门狗保护

- 30秒超时自动复位
- 主循环中定期喂狗

### 4. 双通道通信

| 通道 | 协议 | 用途 |
|------|------|------|
| BLE | 自定义JSON | 本地配置、调试、实时数据查看 |
| 4G | MQTT JSON | 远程数据上报、远程参数下发 |

## 注意事项

1. **水浸模式退出**：退出水浸模式时必须先清除 `s_flood_mode_active` 标志，再重启定时器，否则会导致间隔无法恢复。

2. **DTU配置**：首次使用需通过蓝牙或串口配置MQTT服务器地址和主题。

3. **传感器校准**：WF5803F气压传感器需要在无水状态下设置基准压力。

4. **电池监测**：电池电压低于3.3V时应提醒更换电池。
