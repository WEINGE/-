# BLE UART AT命令项目逻辑说明文档

## 项目概述

这是一个基于汇顶科技(GOODIX) GR系列芯片的蓝牙低功耗(BLE)项目，实现了通过UART接口处理AT命令的功能。项目支持BLE多角色通信，可以作为主设备(Central)或从设备(Peripheral)工作，并集成了传感器数据处理功能。

## 核心架构

### 1. 系统初始化流程

```
启动 → 外设初始化 → BLE协议栈初始化 → 传感器校验 → 主循环
```

#### 1.1 外设初始化 (app_periph_init)
- **GPIO配置**: 设置输入输出引脚，配置上拉下拉电阻
- **UART配置**: 初始化串口通信参数（波特率、数据位、停止位等）
- **定时器配置**: 设置系统定时器和应用定时器
- **中断配置**: 配置各种硬件中断优先级和处理函数

#### 1.2 BLE协议栈初始化 (ble_stack_init)
- **内存分配**: 根据heaps_table配置协议栈所需内存
- **事件注册**: 注册ble_evt_handler作为BLE事件回调函数
- **协议栈启动**: 启动BLE协议栈核心功能

#### 1.3 传感器校验 (sensor_data_test_checksum)
- **自检功能**: 验证传感器数据解析算法的正确性
- **校验和测试**: 确保数据完整性检查机制正常工作

### 2. 主循环任务调度

主循环采用轮询方式处理五个核心任务：

#### 2.1 日志刷新 (app_log_flush)
```c
// 功能：将缓存的日志信息输出到调试接口
// 目的：防止日志缓冲区溢出，确保调试信息及时输出
// 频率：每次循环都执行
```

#### 2.2 AT命令处理 (at_cmd_schedule)
```c
// 功能：检查UART接收缓冲区，解析并执行AT命令
// 支持的命令类型：
// - 连接控制命令 (连接/断开/扫描)
// - 参数设置命令 (波特率/设备名称/广播参数)
// - 状态查询命令 (设备状态/连接状态/传感器状态)
// - 传感器命令 (数据查询/状态清除)
```

#### 2.3 传输调度 (transport_schedule)
```c
// 功能：管理BLE和UART之间的数据传输
// 包括：
// - 发送队列管理
// - 流量控制
// - 重传机制
// - MTU协商处理
```

#### 2.4 UART轮询 (uart_polling_task)
```c
// 功能：处理UART数据的回显和双向通信确认
// 实现：
// - 数据接收确认
// - 错误检测和处理
// - 通信状态监控
```

#### 2.5 电源管理 (pwr_mgmt_schedule)
```c
// 功能：根据系统状态进入相应的低功耗模式
// 策略：
// - 无活动时进入睡眠模式
// - 有BLE事件时快速唤醒
// - 动态调整CPU频率
```

## 核心模块详解

### 3. AT命令处理模块

#### 3.1 命令解析流程
```
UART接收 → 命令缓冲 → 格式验证 → 参数解析 → 命令执行 → 结果返回
```

#### 3.2 支持的AT命令类别

**基础命令**:
- `AT+TEST`: 测试连接
- `AT+VERSION?`: 查询版本信息
- `AT+RESET`: 系统重启
- `AT+BAUD=<rate>`: 设置波特率

**设备信息命令**:
- `AT+ADDR?`: 查询设备MAC地址
- `AT+ROLE?`: 查询GAP角色
- `AT+ROLE=<role>`: 设置GAP角色
- `AT+NAME?`: 查询设备名称
- `AT+NAME=<name>`: 设置设备名称

**连接控制命令**:
- `AT+ADVPARAM=<params>`: 设置广播参数
- `AT+ADVSTART`: 开始广播
- `AT+ADVSTOP`: 停止广播
- `AT+SCANPARAM=<params>`: 设置扫描参数
- `AT+SCANSTART`: 开始扫描
- `AT+SCANSTOP`: 停止扫描
- `AT+CONN=<addr>`: 连接指定设备
- `AT+DISCONN`: 断开连接

**传感器命令**:
- `AT+SENSOR_RX?`: 查询传感器接收状态
- `AT+SENSOR_RX_CLR`: 清除传感器接收标志

#### 3.3 设备状态管理
```c
typedef enum {
    STANDBY     = 0x01,  // 待机状态
    ADVERTISING,         // 广播状态
    SCANNING,           // 扫描状态
    INITIATING,         // 发起连接状态
    CONNECTED,          // 已连接状态
} dev_state_t;
```

### 4. 传感器数据处理模块

#### 4.1 数据结构
```c
typedef struct {
    float concentration;        // 浓度 (%vol)
    float temperature;         // 温度 (°C)
    uint32_t reserved_field;   // 预留字段
    uint8_t status_code;       // 状态码
    uint8_t checksum;          // 校验码
    bool data_valid;           // 数据有效标志
} sensor_data_t;
```

#### 4.2 数据解析流程
```
UART0接收 → 格式验证 → 字段提取 → 校验和验证 → 数据存储 → 标志设置
```

#### 4.3 校验机制
- **格式校验**: 验证数据格式是否符合预定义协议
- **长度校验**: 检查数据长度是否在有效范围内
- **校验和验证**: 使用校验和算法验证数据完整性
- **范围校验**: 验证传感器数值是否在合理范围内

### 5. 传输调度模块

#### 5.1 传输标志管理
```c
typedef enum {
    BLE_TX_CPLT = 0x00,      // BLE发送完成
    GUS_TX_NTF_ENABLE,       // GUS通知使能
    BLE_FLOW_CTRL_ENABLE,    // BLE流控使能
    BLE_TX_FLOW_ON,          // BLE发送流控开启
    BLE_RX_FLOW_ON,          // BLE接收流控开启
} transport_flag_t;
```

#### 5.2 数据流向
```
UART → 环形缓冲区 → BLE发送
BLE接收 → 环形缓冲区 → UART发送
```

#### 5.3 流量控制机制
- **发送队列管理**: 使用环形缓冲区管理待发送数据
- **MTU协商**: 动态调整最大传输单元大小
- **流控状态**: 根据对端设备能力调整发送速率
- **重传机制**: 处理发送失败的数据包

## BLE协议栈集成

### 6. BLE事件处理

#### 6.1 连接事件
- **连接建立**: 处理连接参数协商和服务发现
- **连接断开**: 清理连接资源和状态恢复
- **连接参数更新**: 动态调整连接间隔和超时参数

#### 6.2 数据传输事件
- **GATT通知**: 处理特征值通知和指示
- **数据接收**: 处理来自对端设备的数据
- **发送完成**: 确认数据发送状态

#### 6.3 广播和扫描事件
- **广播报告**: 处理扫描到的设备信息
- **广播超时**: 处理广播超时和重启
- **扫描超时**: 处理扫描超时和停止

### 7. GUS服务集成

GUS (GOODIX UART Service) 是汇顶科技定义的UART透传服务：

#### 7.1 服务特征
- **TX特征**: 用于发送数据到对端设备
- **RX特征**: 用于接收来自对端设备的数据
- **流控特征**: 用于流量控制协商

#### 7.2 数据透传
- **双向透传**: 支持UART和BLE之间的双向数据透传
- **无缝切换**: 用户无需关心底层传输协议
- **自动重连**: 支持连接断开后的自动重连机制

## 电源管理策略

### 8. 低功耗设计

#### 8.1 睡眠模式
- **深度睡眠**: 在无活动时进入最低功耗模式
- **浅睡眠**: 保持必要功能的轻度睡眠
- **快速唤醒**: 收到事件时快速恢复正常工作

#### 8.2 唤醒源
- **UART中断**: UART数据接收唤醒
- **BLE事件**: BLE协议栈事件唤醒
- **定时器**: 周期性任务唤醒
- **GPIO中断**: 外部信号唤醒

#### 8.3 功耗优化
- **动态频率调整**: 根据负载动态调整CPU频率
- **外设按需开启**: 只在需要时开启相应外设
- **智能调度**: 优化任务调度减少不必要的唤醒

## 错误处理和调试

### 9. 错误处理机制

#### 9.1 硬件错误
- **UART通信错误**: 奇偶校验错误、帧错误处理
- **BLE连接错误**: 连接超时、信号丢失处理
- **传感器错误**: 数据异常、通信故障处理

#### 9.2 软件错误
- **内存不足**: 缓冲区溢出保护和恢复
- **协议错误**: AT命令格式错误处理
- **状态异常**: 非法状态转换保护

#### 9.3 调试支持
- **日志系统**: 分级日志输出和过滤
- **状态监控**: 实时状态查询和诊断
- **性能统计**: 传输速率和错误率统计

## 扩展性设计

### 10. 模块化架构

#### 10.1 接口标准化
- **统一的API接口**: 各模块提供标准化的API
- **事件驱动**: 基于事件的模块间通信
- **配置参数化**: 通过配置文件调整系统行为

#### 10.2 功能扩展
- **新AT命令**: 易于添加新的AT命令支持
- **新传感器**: 支持接入不同类型的传感器
- **新协议**: 可扩展支持其他通信协议

#### 10.3 平台移植
- **硬件抽象层**: 隔离硬件相关代码
- **协议栈适配**: 支持不同厂商的BLE协议栈
- **编译器支持**: 支持多种开发环境和编译器

## 总结

本项目采用模块化设计，通过清晰的分层架构实现了BLE和UART的透明传输功能。主要特点包括：

1. **高可靠性**: 完善的错误处理和恢复机制
2. **低功耗**: 智能的电源管理策略
3. **易扩展**: 模块化的架构设计
4. **高性能**: 优化的数据传输和调度算法
5. **易调试**: 完善的日志和诊断功能

该项目可作为BLE应用开发的参考实现，也可直接用于需要BLE-UART透传功能的产品中。
