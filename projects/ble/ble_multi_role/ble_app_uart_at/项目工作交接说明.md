# GR5515 激光气体传感器蓝牙网关 - 工作交接说明

## 项目概述

### 基本信息
- **项目名称**: GR5515 激光气体传感器蓝牙网关
- **芯片平台**: 汇顶科技(GOODIX) GR5515系列
- **开发环境**: Keil MDK-ARM 5, IAR EWARM, GCC
- **协议栈**: BLE 5.0协议栈
- **版本**: 1.0.0
- **开发日期**: 2024-2025

### 项目功能
本项目是一个基于汇顶科技GR5515芯片的智能气体传感器网关系统，主要实现以下功能：

1. **蓝牙低功耗(BLE)通信**: 支持主设备(Central)和从设备(Peripheral)角色
2. **AT命令处理**: 通过UART接口接收和处理AT命令
3. **传感器数据处理**: 集成激光气体传感器数据解析和传输
4. **4G LTE通信**: 通过4G模块实现远程数据传输
5. **JSON协议支持**: 支持JSON格式的BLE协议数据处理
6. **多协议桥接**: BLE与4G协议之间的数据转换和转发

##  核心模块说明

### 1. 主程序模块 (main.c)
- **功能**: 系统初始化和主循环调度
- **关键流程**:
  1. 外设初始化 (`app_periph_init()`)
  2. BLE协议栈初始化 (`ble_stack_init()`)
  3. BLE协议处理初始化 (`ble_protocol_init()`)
  4. 4G协议处理初始化 (`ble_4g_protocol_init()`)
  5. 传感器数据校验测试 (`sensor_data_test_checksum()`)
  6. 主循环任务调度

### 2. 用户应用层 (user_app.c)
- **功能**: BLE事件处理和状态管理
- **关键组件**:
  - GAP参数配置和连接管理
  - GUS服务和客户端事件处理
  - 数据传输调度和缓冲区管理
  - AT命令与BLE协议的桥接
  - 传感器数据更新函数 (`update_sensor_data_from_parser()`)

### 3. AT命令处理器 (at_cmd_handler.c)
- **功能**: 串口AT命令解析和执行
- **支持的命令类型**:
  - 设备控制: `AT:TEST`, `AT:VERSION?`, `AT:RESET`
  - 连接管理: `AT:ADV_START`, `AT:SCAN_START`, `AT:CONN_INIT`
  - 参数配置: `AT:GAP_ROLE=`, `AT:ADV_PARAM=`
  - 传感器操作: `AT:SENSOR_RX?`, `AT:SENSOR_RX_CLR`
  - BLE协议: `AT:BLE_QUERY`, `AT:BLE_REPORT`

### 4. BLE协议处理 (ble_protocol.c)
- **功能**: 处理JSON格式的BLE协议数据
- **支持的协议类型**:
  - 查询请求和响应 (设备信息、状态信息、参数信息)
  - 传感器数据上报
  - 设备状态同步

### 5. 4G协议处理 (ble_4g_protocol.c)
- **功能**: 4G LTE模块通信管理
- **支持的功能**:
  - 设备信息上报 (命令102)
  - 状态信息上报 (命令103)
  - 参数信息上报 (命令104)
  - 监测数据上报 (命令105)
  - 参数设置和查询

### 6. 传感器数据解析 (sensor_data_parser.c)
- **功能**: 解析和验证激光气体传感器数据
- **数据格式**: `+025.50 +28.3 0000000 00 31\r\n`
  - 浓度值: +025.50 (甲烷浓度百分比)
  - 温度值: +28.3 (摄氏度)
  - 预留字段: 0000000
  - 状态码: 00 (十六进制)
  - 校验码: 31 (十六进制)
- **校验机制**: 实现数据完整性验证

### 7. 传输调度器 (transport_scheduler.c)
- **功能**: 管理BLE和UART之间的数据传输
- **特性**: 
  - 环形缓冲区管理
  - 流控制支持
  - 传输状态监控

##  数据流程

### 1. 传感器数据采集流程
```
激光气体传感器 → UART0接收 → 数据解析 → 校验验证 → 缓存存储 → BLE/4G传输
```

### 2. BLE通信流程
```
移动设备 ←→ BLE连接 ←→ JSON协议处理 ←→ 数据转换 ←→ ble传输/更改配置
```

### 3. 4G通信流程
```
4G模块 ←→ 网络连接 ←→ 服务器通信 ←→ 数据上报/参数下发
```

### 4. AT命令处理流程
```
UART接收 → AT命令解析 → 命令执行 → BLE/4G操作 → 响应返回 → UART发送
```

##  编译和部署

### 编译环境要求
1. **Keil MDK-ARM 5.30+**: 主要开发环境
2. **IAR EWARM 8.50+**: 备用编译环境
3. **GCC 9.0+**: 开源编译选项
4. **Python 3.7+**: 用于脚本工具

### 编译步骤
1. 打开Keil MDK-ARM
2. 加载项目文件: `projects/ble/ble_multi_role/ble_app_uart_at/Keil_5/ble_app_uart_at.uvprojx`
3. 选择目标芯片: GR5515
4. 编译项目: Build → Build Target
5. 下载到开发板: Flash → Download

### 部署配置
1. **硬件连接**:
   - 激光气体传感器连接到UART0
   - 4G模块连接到UART1
   - 调试串口连接到UART2

2. **软件配置**:
   - 配置设备名称和广播参数
   - 设置传感器数据采集周期
   - 配置4G模块APN和服务器地址
