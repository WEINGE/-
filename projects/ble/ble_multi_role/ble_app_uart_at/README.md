
## �� 项目概述

### 基本信息
- **项目名称**: GR5515 激光气体传感器蓝牙网关
- **芯片平台**: 汇顶科技(GOODIX) GR5515系列
- **开发环境**: Keil MDK-ARM 5, IAR EWARM, GCC
- **协议栈**: BLE 5.0协议栈
- **版本**: 1.0.0
- **开发日期**: 2024-2025

### 项目功能
本项目是一个基于汇顶科技GR5515芯片的智能气体传感器网关系统，主要实现以下功能：

1. **蓝牙低功耗(BLE)通信**: 支持主设备(Central)和从设备(Peripheral)角色
2. **AT命令处理**: 通过UART接口接收和处理AT命令
3. **传感器数据处理**: 集成激光气体传感器数据解析和传输
4. **4G LTE通信**: 通过4G模块实现远程数据传输
5. **JSON协议支持**: 支持JSON格式的BLE协议数据处理
6. **多协议桥接**: BLE与4G协议之间的数据转换和转发

## �� 核心模块说明

### 1. 主程序模块 (main.c)
- **功能**: 系统初始化和主循环调度
- **关键流程**:
  1. 外设初始化 (`app_periph_init()`)
  2. BLE协议栈初始化 (`ble_stack_init()`)
  3. BLE协议处理初始化 (`ble_protocol_init()`)
  4. 4G协议处理初始化 (`lte_protocol_init()`)
  5. 传感器数据校验测试 (`sensor_data_test_checksum()`)
  6. 主循环任务调度

### 2. 用户应用层 (user_app.c)
- **功能**: BLE事件处理和状态管理
- **关键组件**:
  - GAP参数配置和连接管理
  - GUS服务和客户端事件处理
  - 数据传输调度和缓冲区管理
  - AT命令与BLE协议的桥接

### 3. AT命令处理器 (at_cmd_handler.c)
- **功能**: 串口AT命令解析和执行
- **支持的命令类型**:
  - 设备控制: `AT:TEST`, `AT:VERSION?`, `AT:RESET`
  - 连接管理: `AT:ADV_START`, `AT:SCAN_START`, `AT:CONN_INIT`
  - 参数配置: `AT:GAP_ROLE=`, `AT:ADV_PARAM=`
  - 传感器操作: `AT:SENSOR_RX?`, `AT:SENSOR_RX_CLR`
  - BLE协议: `AT:BLE_QUERY`, `AT:BLE_REPORT`

### 4. BLE协议处理 (ble_protocol.c)
- **功能**: 处理JSON格式的BLE协议数据
- **支持的协议类型**:
  - 查询请求和响应 (设备信息、状态信息、参数信息)
  - 传感器数据上报
  - 设备状态同步

### 5. 传感器数据解析 (sensor_data_parser.c)
- **功能**: 解析和验证激光气体传感器数据
- **数据格式**: `+025.50 +28.3 0000000 00 31\r\n`
  - 浓度值: +025.50 (甲烷浓度百分比)
  - 温度值: +28.3 (摄氏度)
  - 预留字段: 0000000
  - 状态码: 00 (十六进制)
  - 校验码: 31 (十六进制)
- **校验机制**: 实现数据完整性验证

### 6. 4G协议处理 (lte_protocol_handler.c)
- **功能**: 4G LTE模块通信管理
- **特性**:
  - 模块初始化和状态管理
  - AT命令发送和响应处理
  - 网络连接管理
  - 数据传输调度

### 7. 4G协议实现 (lte_protocol_impl.c)
- **功能**: 4G协议的具体实现
- **支持的功能**:
  - 设备信息上报
  - 状态信息上报
  - 监测数据上报
  - 参数设置和查询

## �� 数据流程

### 1. 传感器数据采集流程
```
激光气体传感器 → UART0接收 → 数据解析 → 校验验证 → 缓存存储 → BLE/4G传输
```

### 2. BLE通信流程
```
移动设备 ←→ BLE连接 ←→ JSON协议处理 ←→ 数据转换 ←→ 4G模块
```

### 3. 4G通信流程
```
4G模块 ←→ 网络连接 ←→ 服务器通信 ←→ 数据上报/参数下发
```

### 4. AT命令处理流程
```
UART接收 → AT命令解析 → 命令执行 → BLE/4G操作 → 响应返回 → UART发送
```

## 🛠️ 故障排除

### 常见问题及解决方案

#### 1. 编译错误
- **问题**: 缺少头文件或库文件
- **解决**: 检查包含路径和库文件配置
- **检查**: `custom_config.h` 配置是否正确

#### 2. BLE连接失败
- **问题**: 设备无法被发现或连接
- **解决**: 检查GAP参数配置和设备角色设置
- **检查**: 广播参数和连接参数是否合理

#### 3. AT命令无响应
- **问题**: 串口AT命令没有响应
- **解决**: 检查UART配置和波特率设置
- **检查**: 串口连接和电平匹配

#### 4. 传感器数据异常
- **问题**: 传感器数据解析错误
- **解决**: 检查数据格式和校验码
- **检查**: 传感器连接和数据格式

#### 5. 4G通信失败
- **问题**: 4G模块无法连接网络
- **解决**: 检查SIM卡和网络信号
- **检查**: AT命令响应和网络配置

### 调试技巧
1. **使用RTT日志**: 通过`APP_LOG_INFO`输出调试信息
2. **检查返回值**: 所有API调用都要检查返回值
3. **监控状态机**: 关注设备状态转换和事件处理
4. **验证数据完整性**: 使用校验和验证传感器数据
5. **使用示波器**: 检查UART信号和时序
